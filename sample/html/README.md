# sample/html — writer の HTML 読みの受入サンプル

writer の「HTML — JS なしの閲覧と記入」(SEKKEI の同名の節、HIKITSUGI の
段階①〜④)を実装するときの**受入試験の材料**。1ファイル=1つの焦点で、
**ページ自身が「何が見えるべきか」を本文で語る**(開けば自分で検査できる)。
中身はすべて架空。すべて UTF-8(90・91 だけ意図的に CP932)。

サーバーと組み合わせる試験(06・07)は先に見本サーバーを立てる:

```bash
python3 sample/catalog_server.py     # 127.0.0.1:8765
```

| ファイル | 段階 | 試すもの | 合格の見え方 |

| 02_hyo.html | ① | 表(th/td)・**閉じ忘れの癒し**(td/tr の省略) | 2つの表が同じ 3×3 に見える |
| 03_kajo.html | ① | 箇条書き・番号リスト・入れ子 | 印と番号、1段の字下げ |
| 04_e.html | ① | **img**(相対パスの SVG と PNG・外部 URL) | 相対の絵2枚が出る。**外部 URL は取りに行かず**帳簿へ |
| 05_form.html | ② | form の表示と記入(input text・submit) | 記入欄に書ける。送信はまだ飛ばなくてよい |

## 期待挙動の根拠(SEKKEI / HIKITSUGI より)

- 目標は「文書として読める・刷れる」。ブラウザの再現ではない
- 癒しは p/li/tr/td の自動閉じだけ。実体参照は基本5つ
  (`&amp; &lt; &gt; &quot; &apos;`)+数値(`&#NNNN;` `&#xHHHH;`)
- 未知タグは**中の文字を拾い、殻は帳簿へ**(黙って落とさない)
- img は同一サーバー / ローカル相対のみ。**別ホストへは取りに行かない**
- JS は実行しない・読み飛ばす。`<script type="py">` は文書の一部として保ち、
  **開いても実行しない** — 明示の操作で bubblewrap の檻(form 束縛)
- **文字コードは CP932 も読む**(発注者 2026-08-04。閉域の古いイントラは
  CP932 の巣 — 断る相手が本命の客になってしまう)。判定の順は
  宣言 → UTF-8 として妥当か → CP932 → どれでもなければ正直に断る。
  CP932(Windows-31J)で読むこと — ①髙﨑㈱ が純正 Shift_JIS には無い

07 の form 束縛(`form` 辞書の出入り)の書き戻しの作法は実装時に確定する。
ページ側は「`form["金額"]` に代入すれば紙面の同名欄に戻る」を仮置きしている。

## 開き方(実装後)

```bash
./target/release/writer sample/html/01_bunsho.html
```

ブラウザでも同じものが見える(06・07 はサーバー経由で):
どのページも writer とブラウザで**同じ文書**に見えることが受入の物差し。
