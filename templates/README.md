# 台帳テンプレ集 — 「N 個のブック」の実証

**新しいソフトはバイナリではなくブック**(SEKKEI「端末のソフトの土台として」)。
このフォルダの xlsx は、帳票+コード(檻つき)+運用が1つになった「業務アプリ」の見本。
共有フォルダに置いてコピーして使う。作り直しは `cargo run -p sheet --example gen_templates`。

## 問い合わせ台帳.xlsx

Web フォームの受信箱を事務で回す台帳。

- 状態列は三択(未対応/対応中/完了 — 入力規則)
- H2 の `=PY("状態集計", …)` は、データ > Python の板で **@計算** すると
  状態ごとの件数がスピルで出る
- 同梱「取り込み」: フォームの CSV URL を書き換えて **@取り込み net** で
  新着を追記(網あり檻 — 許可はその場の操作だけ)

## 在庫台帳.xlsx

- 在庫金額は式(=在庫数×単価)。**@計算** で「要発注」(在庫数<発注点の品)が
  スピルで出る

## 勤怠表.xlsx

- 曜日は日付関数(WEEKDAY/DATE)。出勤・退勤を「9:00」の形で打ち、
  **@計算** で実働h(休憩1時間引き)が埋まる。合計は SUM

## 共通の約束

- **開いただけでは何も実行されない。** 同梱コードは @名前 / @計算 の
  明示の操作だけで、必ず檻(bubblewrap)の中で動く
- 同僚が Excel で開いても値は見える(PY セルは Excel では #NAME? になる。
  同梱コードは Excel の保存で消えることがある — 原本はこのフォルダに)
