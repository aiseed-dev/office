# Excel から来た人の手引き(蒸留の台帳を兼ねる)

2026-08-08 起こし(発注者「Excel のマニュアルを蒸留して officework の
マニュアルを作りませんか」)。**Excel の公式ヘルプの課題の並びを教師**にして、
「Excel でやっていたあの仕事は、ここではこうやる(またはやらない、なぜなら)」
を課題ごとに書く。文章は写さない — 構成と課題の一覧だけが教師
(vendor を挙動の教師にした台帳と同じ流儀)。

⏳ = まだ薄い(本家ヘルプとの突き合わせは第一稿のあと。詳しい操作は
[calc の手引き](calc-manual.ja.md) へリンクで送る)。

## データを他のシステムから持ってくる(Get & Transform / コネクタ)

Excel の答えは Power Query と Copilot コネクタ(基幹のデータを Microsoft
Graph に索引させ、クラウド経由でグリッドへ)。**officework の答えは手元**:

- CSV / テキスト → **テキスト取り込みウィザード**(文字コード・区切り・
  置き場所をプレビューで)
- 基幹の API・チケット・DB → **plugins の手続き**(`@名前 net`)が polars で
  引いて台帳へ刻む。データは**基幹網の外に出ない**。見本:
  [問い合わせ台帳](../templates/README.md)・[受注台帳](../sample/README.md)
- Jupyter・既存の Python 資産から → **officework**
  (`from officework import calc as xw` — xlwings の1行差し替え)
- 「古くなった CSV から作業」問題への答えは**取り込みの手続きを台帳に
  据え付けて毎回引き直す**(取込済みの控えで重複しない)

## 数式と関数

- 四則・比較・絶対参照・名前・スピル(=FILTER 等の動的配列)は同じ作法
- R1C1 の見せ方切り替えあり(中身は A1 のまま)
- 対応する関数の一覧 → calc の手引きの関数の節。⏳ Excel 関数名ごとの
  対応表(ある/ない/代わり)はこれから
- **=PY はこちらが先に地元で動く**(Excel の Python はクラウド実行・従量課金。
  こちらは手元の檻の中・無料)

## ピボットテーブル

フィールドリスト・▼の絞り込み(ラベル/値)・グループ化(月/四半期/年/
数の幅)・スタイル・更新 — Excel の作法どおり。中身の集計は polars。

## テーブル・並べ替え・フィルター

テーブル(縞・合計行 SUBTOTAL 8択・スライサー)、複数基準の並べ替え
(色基準も)、オートフィルタ。⏳ スライサーの詳細設定は台帳に残件あり。

## 条件付き書式

セルの強調・上位/下位・データバー・カラースケール・アイコンセット+
ルールの管理。紙(PDF)への描画は控えめ(正直にそう言う)。

## グラフ

選択範囲から matplotlib が描いて**画像として**浮かぶ(Excel のグラフ部品
ではない — Excel で開くと画像に見える。劣化は安全側で正直に)。

## 入力規則(データの入力規則)

リスト・数値範囲・日付など、本家の3タブのダイアログの形。▼の表示切替も往復。

## What-If 分析

ゴールシーク・ソルバーあり。⏳ データテーブル(感度表)は未対応 — 台帳参照。

## 共同編集

Excel の答えはクラウドの共同編集。**officework の答えは共有フォルダ**:
排他ロック(誰が開いているか見える・後勝ちで潰さない)、セルのコメント
(xlsx 往復)、ファイル越しのチャット、バージョン履歴(9世代)。
生放送の同時編集は**やらない** — サーバーを持たないため(設計の
[ネイティブファースト](sekkei/ayumi.ja.md)参照)。

## マクロと自動化(VBA → Python)

- VBA は**意図して積まない**(開く=実行の30年の穴を持ち込まない)。
  役目は Python が担う: [Python の手引き](python-manual.ja.md)
- **ブックが運べるのは =PY の関数だけ**。手続き(取り込み等)は
  `~/.config/office/plugins/` に自分で置いた .py だけが動く —
  受け取ったファイルは実行の起点になれない(2026-08-08 確定)
- VBA の移し替え: olevba で取り出し → AI に「申し送り」と一緒に渡す →
  檻で試す(Python の手引きの型どおり)

## AI(Copilot に相当するもの)

AI タブ(表にする・式を書く・マクロを書く)。**AI はコードを書く係で、
実行は常に人の明示の操作+檻** — Copilot コネクタのように AI とデータ搬入を
束ねない。データの道は上の「持ってくる」の節(AI 無しで成立する)。

## 印刷・ページレイアウト

改ページ・拡大縮小(幅/高さ)・ヘッダー/フッター(&P/&N)・タイトル行・
枠線と見出しの印刷。紙は PDF と同じ紙面(画面=紙)。

## 保護・校閲

シート保護(パスワードは掛けない — 掛けた振りもしない)、ブックの暗号化
(AES-256 Agile。Excel でも開ける)、隣に置く署名(.sig)。
⏳ 変更履歴(校閲の記録)は writer にはあるが calc は未対応。

## 開けない・化けるとき

読めない部品は**開くときの報告**に出る(黙って落とさない)。保存で消える
物は保存前にそう言う。Excel で開き直したときの見え方は各節に明記
(=PY は #NAME? だが値は残る、等)。

## ⏳ これから埋める節(本家ヘルプの並びで)

入門(画面の対応表)・データの入力と書式の細部・ショートカット対応表・
関数の対応表・アクセシビリティ。本家ヘルプ全節との突き合わせ
(第2便と同じ調査の型)は発注者と相談して回す。
