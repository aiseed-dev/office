## 入門 — 画面と基本操作

タブの並びは本家どおり(ファイル/ホーム/挿入/描画/レイアウト/数式/データ/
ピボットテーブル/表のデザイン/共同編集/保護/表示/プラグイン+AI)。帯は一段の
アイコンで、乗ると名前が下のステータスバーに出る。押しても動かない釦は原則
置かない — 数少ない灰色の釦は「場所だけ」の明示(保護の節を見よ)。
詳しくは [calc の手引き](calc-manual.ja.md)の「画面」「基本操作」。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| 新規・開く・保存 | 同じ | ファイルタブ+Ctrl+O / Ctrl+S。保存は xlsx が正、CSV 書き出し(UTF-8 BOM+CRLF・値だけ)あり。ODS・XLTX は控え(台帳) |
| 最近使ったブック | 同じ | ファイルタブに12件 |
| シートの追加・削除・名前変更・移動・コピー | 同じ | タブの右クリック。移動はドラッグでなく「左へ/右へ移動」。名前を変えると式の中の `古い名前!` も追随し、直した件数を状態行で言う(ただし `INDIRECT("古い名前!A1")` のような**文字列の中は追随しない**(Excel も同じ — INDIRECT は「動かない参照」を作る道具だから)。**残っている数は改名のとき状態行で言う**ので手で直せる) |
| シートの非表示・再表示・タブの色 | 同じ | 右クリック。隠しシートは表示タブ「シートの表示」からも戻る。最後の1枚は隠せない |
| 行・列の挿入・削除 | 同じ | 右クリックで本家と同じ4択。ホームの釦は行に固定(台帳に残件) |
| 列幅・行高の変更 | 同じ | 境界のドラッグ+右クリックの数値指定(0〜255 / 0〜409pt) |
| 境界ダブルクリックの自動調整 | 作らない | 掴み直しのドラッグを自動調整が横取りする事故を防ぐため撤去(2026-08-03 発注者確定) |
| 行・列の非表示・再表示 | 同じ | 見出しの右クリックに「非表示」「再表示」(**2026-08-08 実装**)。再表示は隠れた分を挟むように選んでから。器はグループ化と同じで xlsx と往復する(隠したまま次の人に渡る)。**使っている分を全部は隠せない** — 戻す道が見えなくなるので断る |
| ウィンドウ枠の固定 | 同じ | 表示タブから最上行・最初の列・いまの位置・解除。境目に緑の線、影の切替も |
| 表示倍率(ズーム) | 同じ | 50〜200%(本家500%より狭い)。紙は変わらない。画面の文字の大きさは詳細設定で別に |
| ウィンドウの分割 | まだ無い | 見出しなら枠の固定、値の見張りなら数式タブのウォッチで代替(台帳に未記載 — 在庫候補) |
| 新しいウィンドウ・整列 | 違う形 | 1ブック=1窓。並べるならもう一度起動して OS の窓で。別ブックをクリックして外部参照式を作る道は作らない(下の「持ってくる」) |
| 数式バー・枠線・見出しの表示切替 | 同じ | 表示タブ。「0を表示する」の切替もある |
| ステータスバーの合計・平均・個数 | 同じ | 選択でリアルタイムに出る。絞り込みを尊重する |

## データの入力と書式

セル書式の細部(罫線・塗り・文字の配置・折り返し・縦書きなど)の本家ヘルプ
との突き合わせはまだ薄い — 末尾の「これから埋める節」。ここにあるのは
検証済みの分だけ。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| オートフィル(■をドラッグ) | 違う形 | フィルハンドルは無い。先頭行を選び Shift+↓ で広げてホームの「フィル」— 先頭行を下へ写す(下方向のみ)。相対参照はずれ、書式も写る |
| 連続データの作成(1,2,3…) | 違う形 | フィルは複写だけで当て推量をしない。連番は =SEQUENCE(10) のスピルか、=A1+1 をフィルで。曜日・月名のユーザー設定リストは無い |
| フラッシュフィル(Ctrl+E) | まだ無い | AI タブ「続きを書く」か データ > Python が代わり(台帳に未記載 — 在庫候補) |
| 値だけ貼り付け | 同じ | Ctrl+Shift+V。右クリックの「形式を選択して貼り付け」からも |
| 形式を選択して貼り付け | 違う形 | 4択 — 値だけ/式をそのまま/書式だけ/転置(値)。演算・空白を無視・列幅は無い |
| 書式のコピー(刷毛) | 同じ | 貼り付けの隣。次に押したセル(Shift で範囲)に塗り、Esc でやめる |
| 表示形式(桁区切り・通貨・日付…) | 同じ | ホームの一覧に ✓ 付き。会計・分数は控え(台帳) |
| ユーザー定義の表示形式 | 違う形 | 「その他(書式コードを打つ)…」でコード直打ち。コードは xlsx そのままなので Excel と往復 |
| セルを結合して中央に配置 | 同じ | 本家と同じ4択。**左上以外の値は消える**(左上が空なら最初の中身を書式ごと移してから)。確認は出さず状態行で言い、Ctrl+Z 一発 — 隠れた値が SUM に効いて帳票が静かに嘘をつくのを防ぐ設計 |
| 図形(オートシェイプ)の挿入 | 違う形 | 6種のみ(四角・角丸・楕円・右矢印・ひし形・直線)。中に文字も書ける。大きなギャラリーは無い(台帳) |
| 図形の操作と書式 | 同じ | 移動・リサイズ・回転(Shift で15度)・Ctrl+クリックの複数選択と整列/分布・重なり順・塗り/線/影の板。xlsx と往復 |
| 図形のグループ化 | まだ無い | 釦は灰色で場所だけ(台帳)。当座は複数選択でまとめて動かす |
| 画像の挿入 | 違う形 | PNG/JPEG/BMP/GIF。移動・リサイズ・Del。回転・トリミングは控え。**他所のブックに元から入っていた画像は動かせない**(原文を壊さないため — そう言う) |
| テキストボックス | 違う形 | 枠の図形+文字。段落設定(箇条書き等)は無い(台帳) |
| セル内改行(Alt+Enter) | 同じ | 折り返しの入切もホームに |

## セル書式の基本

書式の道具はホームの帯にほぼ揃っていて、押せば効き、xlsx と往復する。
違いは二つの流儀に出る — 罫線は本家の型スタンプでなく**場所×ペンの
直交モデル**、そして「セルの書式設定」は6タブのダイアログでなく開けたまま
使える小窓。詳しくは [calc の手引き](calc-manual.ja.md)。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| フォント(書体)と文字の大きさの変更 | 同じ | ホームの一覧から選ぶ(釦にいまの値が出る)。書体はこの機械にある日本語の書体だけを出し、無ければ「見つかりません」と言う。大きさは 6〜72 の並び+「大きく/小さく」で 4〜72pt を1pt ずつ。任意サイズの直打ち欄は無い |
| 太字・斜体・下線・取り消し線 | 同じ | ホームの釦で入切(Ctrl+B/I/U/5 のキーは未配線 — ショートカット表)。斜体は書体が斜体面を持つときだけ斜まり、和文書体では出ない(疑似斜体は作らない)。二重下線・会計下線の変種は無い |
| 文字の色・塗りつぶしの色 | 同じ | ホームの釦でパレット(文字色は自動+10色、塗りは色なし+薄い5色+濃い5色)から。「その他(RRGGBB を打つ)…」でコード直指定も。スポイト・テーマカラーの升は無い。グラデーション・パターンの塗りは無い(単色のみ) |
| 罫線を引く(外枠・格子・太線・二重線・色) | 違う形 | 「太い下罫線」等の型スタンプは持たない。持つのは直交した2つだけ — 場所9種(下・上・左・右・外枠・格子・内側の縦・内側の横・消す)をアイコンの格子パレットで選び、ペン(線種12種と色)を別に選ぶ。太い外枠が欲しければペンを中太にして外枠。パレットは掛けても閉じないので連打で帳票の枠を組める。xlsx と往復する |
| 斜め罫線(セルに斜線を引く) | まだ無い | 辺は上下左右の4つだけで、斜めはモデルに無い。他所の xlsx に斜め罫線があっても読まず、**保存で落ちる**(原文持ち越しにならない数少ない場所)。取り消しの意味の斜線なら取り消し線か図形の直線が当座の代わり(台帳) |
| 文字の配置(左・中央・右/上・中央・下・両端揃え) | 同じ | ホームの釦で横3種+両端揃え、縦3種。既定は本家と同じ「数は右、文字は左」「縦は下」。両端揃えは折り返しも一緒に入れる(揃えるには折り返しが要る)。均等割付(distributed)は無い |
| 折り返して全体を表示 | 同じ | ホームの釦で入切。画面の描きも xlsx(wrapText)の往復も揃っている。セル内改行(Alt+Enter)とも併用できる |
| 縮小して全体を表示 | まだ無い | 入切の釦がまだ無い。xlsx で既に掛かっているセルは正しく読んで幅に収まるまで縮めて描き、保存でも失わない — 欠けているのは操作の口だけ(台帳) |
| 縦書き・斜めの文字(文字の向き) | 違う形 | ホームの向きの釦(名札は「印刷の向き」のまま — 名前のずれ)でプリセット6種(角度なし・左上がり/右下がり45度・上向き/下向き90度・縦書き=1字ずつ積む)+「その他(角度を打つ)…」で -90〜90 度。いまの向きに ✓ が付き、値は往復する。ただし**画面は字を回さない** — 0度以外はどれも1字ずつの縦積みで見せる。日本の帳票の縦の見出しは狙いどおりだが、45度の斜め文字が斜まるのは Excel で開いたとき |
| 上付き・下付き文字 | 違う形 | 下付きはホームの釦で入切し往復する。上付きはモデルに無く控え(calc のホームに釦は置いていない) |
| インデント(セル内の字下げ) | まだ無い | calc に字下げの釦もモデルの欄も無い(writer の段落には積んでいる)。当座は先頭に空白を打つか列を分ける(台帳) |
| セルのスタイル(見出し・良い/悪いなどの既定の組) | 違う形 | ホームの「セルのスタイル」で10種(標準・見出し・表題・良い/悪い/どちらでもない・メモ・計算・通貨・パーセント)。選ぶと選択に書式が掛かり、Ctrl+Z の1手で戻る。大きなギャラリー・自作スタイルの登録・スタイルの変更(一括更新)は無い — 掛かるのはただの書式なので、直すのは書式を直す |
| ブックのテーマ・テーマの色 | 違う形 | テーマ丸ごと(色+フォント+効果)の切替は無く、レイアウトの「配色の変更」で色の組4つ(Office/暖色/寒色/墨)を入れ替える。テーマ由来の色は由来ごと覚えて往復するので、配色を変えるとそのセルの色が追従し、保存も rgb に潰さない。表示タブの「インターフェイステーマ」は画面の明暗であってブックのテーマではない(セルは白のまま)。テーマのフォント・効果の組は持たない |
| セルの書式設定ダイアログ(Ctrl+1) | 違う形 | 6タブのダイアログでなく「セルの書式」の小窓 — 罫線・塗り・文字色・文字飾り・揃え・折り返し・表示形式を1枚に並べた道具箱。ホームでの名札は「セルのスタイル」で、隣の本物のスタイル一覧と同名なので見分けにくい(板の題は「セルの書式」)。モーダルにせず、範囲を選び直しながら開けたまま使え(閉じるのは ✕ か Esc)、どの釦も1手ずつ Ctrl+Z で戻る。Ctrl+1 のキーは未配線 |

## 入力を助ける仕掛け

Excel が「気を利かせる」仕掛け — ユーザー設定リスト、シートに浮かぶフォーム
コントロール、複数シートを束ねる作業グループ — は、どれも**画面の外に状態を
持つ**点が共通している。この家の線は「状態はセルに置く」で、リストはシートの
範囲、部品はセルそのもの(チェックボックス)、複数シートへの書き込みは
データ > Python の明示の指名。当て推量と、見えていないシートを黙って書き換える
道は作らない。詳しくは [calc の手引き](calc-manual.ja.md)。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| ユーザー設定リストの作成(オプションの「ユーザー設定リストの編集」) | まだ無い | リストを登録する設定画面は無く、アプリ側にリストを保持する仕組み自体が無い。当座はリストをシートの1列に書いて範囲のまま使う(入力規則のドロップダウンの元の値として指すか、MATCH の順位表として参照する)(台帳に未記載 — 在庫候補) |
| セル範囲からユーザー設定リストをインポート | まだ無い | 取り込み先のリスト置き場が無いので、範囲は範囲のまま使うのがこの家の道。リスト列を1枚のシートに置き、名前を定義して式から指せば、リストの改廃はセルの編集で済む |
| 独自の連続データのオートフィル(「東京, 大阪…」をドラッグで一巡) | まだ無い | フィルハンドルが無く、ホームの「フィル」は先頭行を下へ複写するだけで当て推量をしない。一巡させたい時はリスト列を丸ごとコピーして必要なだけ継ぎ足すか、`=INDEX($A$1:$A$5, MOD(ROW()-1,5)+1)` を先頭に置いて「フィル」で下へ写す。SEQUENCE を INDEX の中に入れてもあふれない — スピルするのは FILTER・SORT・UNIQUE・SEQUENCE・TRANSPOSE を四則・比較・& と組み合わせた式までで、普通の関数の中では1つの値に潰れる |
| 曜日・月名の連続データ(「月」からドラッグで火・水・木…) | 違う形 | 組み込みの曜日・月名リストは無い。曜日・月名は文字列でなく日付から作る — 日付を1列に連ね、表示形式か `=TEXT(A1,"aaa")`/`"aaaa"` で「水」「水曜日」に、月は `"m月"` で「8月」にする(英字の mmm は月名にならず「08」のような数で出る)。並べ替えも計算も日付のまま効くのが利点である |
| 日付の連続データの単位指定(日・週日・月・年単位のフィル) | 違う形 | 右ドラッグの単位メニューは無い(台帳)。式で単位を書く — 日は `=A1+1`、平日は `=WORKDAY(A1,1)`、月は `=EDATE(A1,1)`、年は `=EDATE(A1,12)` を先頭に置いて「フィル」で下へ写す。フィルは相対参照をずらして写すので、写した先は直前の日付を見て次を出す |
| 連続データの作成ダイアログ(加算・乗算・停止値・増分値) | 違う形 | ダイアログは無い。加算の列は `=SEQUENCE(件数, 1, 開始, 増分)` のスピル1本で出る。乗算(成長)は `=A1*倍率` をフィルで、停止値は件数に換算して自分で決める |
| 書式なしのフィル(オートフィルオプションの「書式なしコピー」) | まだ無い | 「フィル」は帳票の列を書式ごと揃える設計で、値だけ写す選択肢は無い。書式を残したくなければフィルの後に範囲を選んで書式のクリア(値は消えない)で整え直す |
| ユーザー設定リストの順で並べ替え(役職順・S/M/L 順) | まだ無い | カスタムソートは見出し名を左から強い順に並べて複数基準を受けるが、向きは昇順・降順の2択だけで独自の順は指せない。補助列に `=MATCH(値, リスト範囲, 0)` でリスト内の順位を振り、その列を基準に「順位 昇順」で並べ替えるのが当座の道 |
| SORTBY 関数で任意の順に並べる | まだ無い | SORTBY は無い(関数対応表に明記)。順位の補助列を範囲の中に足し、`=SORT(範囲, 順位列の番号, 1)` のスピルで同じ結果を出す |
| ピボットテーブルの行ラベルをユーザー設定リスト順に並べる | まだ無い | ピボット自体の並べ替えがまだ無く(台帳)、リスト順はなおさら無い。ピボットの結果はただのセルなので、右の空きに順位表を置いて手で組み替えるか、元データに順位列を足して先に並べておく |
| ユーザー設定リストはブックに付いて回るか | まだ無い | リストを持つ仕組みがアプリ側に無いので、「ブックに付いて回るか」を問う土台がまだ無い。この家の道はリストをシートの範囲として持ち、名前を定義して指すことなので、ブックを渡せばリストも一緒に渡る — 環境に依存しない分むしろ運びやすい |
| 開発タブを表示してフォームコントロールを使う | 違う形 | 開発タブそのものが無い。役目は分かれていて、チェックボックスは挿入タブ、Python(マクロの後継)はプラグインタブが受け持つ。オプションでタブを出す手続きは要らない |
| セルにチェックボックスを挿入する | 同じ | 挿入タブ「チェックボックス」。空のセルに置くと ☑/☐ になる(値は TRUE/FALSE の bool)。中身のあるセルは潰さず、その旨を状態行で言う |
| チェックボックスをキーで ON/OFF し、値を数式で使う | 違う形 | 空白キーで切り替わるのは Excel と同じ。値も普通の TRUE/FALSE なので `=E4` や `=IF(E4,…)` はそのまま通る。ただし裸の TRUE を条件に渡す `=COUNTIF(E:E,TRUE)` は 0 を返す — 数えるなら `=COUNTIF(E:E,"TRUE")`、`=COUNTIF(E:E,1)`、`=SUMPRODUCT(--(E:E=TRUE))` のどれかを使う。保護中のシートでは切替を断って理由を言う |
| 範囲にチェックボックスをまとめて置く・削除する | 同じ | 範囲を選んで挿入すると空のセルにだけ一括で置かれ、何個置いたかを言う。消すのは Delete で値ごと消すだけ — 部品と値の二重帳簿が無い |
| チェックボックスを Excel と往復しても ☑/☐ のまま見せる | 違う形 | 保存は素の TRUE/FALSE で、Excel 365 のチェックボックス書式(部品の見た目)は書かない。Excel で開くと TRUE/FALSE の文字で見え、値と式は完全に通じる。逆に TRUE/FALSE の値を持つセルはどれも officework 側で ☑/☐ に見える |
| フォームコントロールのチェックボックスと「リンクするセル」 | 違う形 | セルの上に浮かぶ部品は作らず、セルそのものが部品(bool 値)。部品とセルを紐づける「リンクするセル」という別建ての手続きは要らない — セル自身が値だからだ |
| スピンボタン・スクロールバーで数値を増減させる | まだ無い | 増減の部品は無い。数値はセルに打つか、入力規則の整数・小数の範囲で上下限を守らせるのが今の道(台帳に未記載 — 在庫候補) |
| リストボックス・コンボボックスで一覧から選ばせる | 違う形 | 浮かぶ部品ではなく、入力規則のドロップダウンリストが同じ用を足す。許可=リストで直書きか範囲参照、セル右下の ▾ から選ぶ。選んだ値はそのセルに入るので「リンクするセル」は不要だ |
| オプションボタン(ラジオ)とグループボックスで排他の一択 | まだ無い | 排他の丸ボタンとグループボックスは無い(writer のフォームフィールドには在るが calc には無い)。一択は入力規則のドロップダウンリストで代えるのが今の道(台帳に未記載 — 在庫候補) |
| 既存ブックのフォームコントロールを開いて表示し、保存後も残す | まだ無い | 古いフォームコントロール(VML)や部品の参照は読まれず画面に出ない。保存ではシート本体と vmlDrawing を作り直すため、原本の部品参照が持ち越されず失われる。図形・画像は持ち越すが、コントロールはその外だ(台帳に未記載 — 在庫候補) |
| ActiveX コントロール(コマンドボタン・テキストボックス等) | 作らない | ActiveX は VBA イベントと不可分で、「開く=実行」の口をブックに持ち込まないのがこの家の第一原則。押して動く仕掛けが要るなら、plugins に置いた Python を自分で明示に呼ぶ |
| 複数シートをまとめて選択する(Ctrl+クリックで作業グループ) | まだ無い | 選択は常に1枚。タブを押すとそのシートへ切り替わるだけで、修飾キーは見ない。束ねた状態(作業グループ)という概念自体が無い(台帳に未記載 — 在庫候補) |
| すべてのシートを選択(タブの右クリックから一括選択) | まだ無い | タブ右クリックのメニューは挿入・削除・名前の変更・コピーを作成・左右へ移動・非表示・再表示・タブの色の9項目で、どれも1枚が相手。全選択の項目は無い(台帳に未記載 — 在庫候補) |
| グループへの同時入力(1枚に打つと全シートの同じセルに入る) | まだ無い | 入力は常にいまのシート1枚。同じ物を複数シートへ書くなら データ > Python で `b["シート名"]` を明示に指名して書く — 複数シートに触っても Ctrl+Z 1回で戻る(台帳に未記載 — 在庫候補) |
| グループでの一括書式設定・行や列の挿入削除を全シートへ | まだ無い | 書式も行列の挿抜もいまのシート1枚に効く。複数枚を同じ姿にしたければ、1枚を仕上げてからシートの「コピーを作成」で増やすのが代わり(台帳に未記載 — 在庫候補) |
| グループの解除・解除し忘れ(全シートを壊す事故) | まだ無い | 束ねる状態が無いので、解除の操作も解除し忘れの事故も存在しない。Excel でこの事故に懲りた人には、無いことがそのまま答えになる |
| 選択したシートをまとめて印刷・ブック全体を印刷 | 作らない | 印刷(=PDF)は常にいまのシート1枚 — 印刷対象を切り替える UI は独自の割り切りとして持たない。複数枚はシートごとに PDF へ出す |
| ページ設定を複数シートへ一括で効かせる | まだ無い | レイアウトタブの設定はいまのシート1枚に効く。揃えたければシートごとに設定するか、設定済みのシートを「コピーを作成」で増やしてから中身を入れる(台帳に未記載 — 在庫候補) |
| 作業グループへの複写(フィル ▸ 作業グループ) | まだ無い | フィルは1シート内の下方向のみ。複数シートの同じ位置へ写すなら、コピーして各シートに貼るか、データ > Python で `b["シート名"]` へ書く台本を plugins に置く(台帳に未記載 — 在庫候補) |
| 同じ様式のシートを月別・部署別に揃えて増やす | 違う形 | 1枚を様式ごと仕上げ、タブ右クリック「コピーを作成」で増やす。書式・式ごと写り、名前を変えれば式の参照も追随する。グループで後から一斉に直すのではなく、雛形を先に固めてから増やす順番 |
| 複数シートの一括削除・一括非表示 | まだ無い | 削除も非表示もタブ右クリックで1枚ずつ。最後の1枚は隠せない・消せない守りはある |

## 数値の精度と入力の落とし穴

数の器は f64 ひとつで、Excel の「有効桁15桁で切る」化粧はしない。代わりに
**打った文字をどう読むかの当て推量もしない** — 日付にも化けない代わりに、
先頭の `'` もテキスト書式も入力の解釈を変えない。守る道具が薄い分、番号を
文字として正確に持ちたい仕事は今のところ苦手である。表示形式は
[calc の手引き](calc-manual.ja.md)の「表示形式」。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| 有効桁数15桁の壁(16桁のカード番号などの末尾が 0 に化ける) | 違う形 | 値は f64 のまま持ち、「15桁で切り捨て」はしない — 16桁の 4111111111111111 はそのまま出る。ただし 2^53(約9,007兆)を超える整数は二進の丸めで変わり、9999999999999999 と打つと 10000000000000000 になる。文字列として打って守る逃げ道は今のところ無い(下の「数値を文字列として入力する」) |
| 長い数値が勝手に指数表示(1.23E+11)になる | 違う形 | 一般(書式なし)の表示は指数へ自動で切り替えない — 何桁でも全桁をそのまま出す(1e21 と打つと 1000000000000000000000、1e-7 は 0.0000001)。指数で見たいときはホームの表示形式の一覧から「指数 (1.23E+04)」を明示に選ぶ |
| 「2E3」「1E9」のような品番が指数と読まれて数に化ける | 同じ | 入力は Rust の f64 パーサで読むため、2E3 は 2000 に化ける — Excel と同じ落とし穴である。さらに inf・nan の綴りも数として読まれ、画面には inf・NaN と出る |
| 浮動小数点誤差(0.1+0.2 が 0.3 にならない) | 違う形 | 表示は化粧をせず 0.30000000000000004 とそのまま出る。一方で式の比較は f64 の刻み幅(約2.2e-16)だけ甘く見るので `=0.1+0.2=0.3` は TRUE になる — ただし `>` は甘く見ないため `=(0.1+0.2)>0.3` も TRUE で、= と > が同時に真という食い違いが出る。範囲どうしの比較(スピル)は甘さ無しの厳密比較。丸めたい桁は ROUND・ROUNDDOWN・ROUNDUP を式に書くのが道 |
| 小数点以下の表示桁数を減らすと見た目だけ丸まる | 同じ | ホームの「小数を増やす/減らす」は書式コードの小数桁を書き換えるだけで、格納値は変えない(0〜10 桁で頭打ち)。計算は常に本当の値 — Excel の既定と同じ |
| 「表示桁数で計算する」オプション(Precision as displayed) | まだ無い | 格納値を表示桁に切り詰めるオプションは無い。丸めた値で計算したければ ROUND を式に入れる(こちらは Excel でも推奨の道)(台帳) |
| 文字列になった数値(左寄せのまま SUM に入らない) | 違う形 | SUM・AVERAGE は範囲の中の「数字だけの文字列」を数として読むため、黙って合計から抜け落ちない。VLOOKUP・MATCH の完全一致も表示文字で比べるので "123" と 123 は合い、SUMIF・COUNTIF の数の条件も合う。合わないのは COUNT(Number だけ数える)と ISNUMBER(FALSE)。数に戻すには =VALUE(¥ と桁区切りも外して読む)か NUMBERVALUE を別列に出して「値だけ貼り付け」(Ctrl+Shift+V) |
| 緑三角のエラーチェック(エラーインジケーター・「数値に変換」) | まだ無い | セル隅の印も、背景のエラーチェック規則も、一括修正も無い。文字列数値の検分は =ISTEXT・=ISNUMBER を補助列に書いて自分で洗う(台帳) |
| 全角で打った数字(IME のまま確定した 123) | まだ無い | Excel は確定時に半角の数へならすが、セル入力の確定にはならしが無く、全角の数字はそのまま文字列になる。しかも全角は SUM の文字列読みも効かず 0 扱い、入力規則(整数・小数)の判定にも通らず弾かれる。ならしが効くのは入力規則の板に打つ条件値だけで、既にあるデータは =ASC で半角に直してから =VALUE(台帳) |
| 桁区切りや記号付きで打った数(1,234・¥1,234・5%) | まだ無い | f64 パースに通らない綴りはすべて文字列になる。数は素の半角で打ち、見た目はホームの表示形式(桁区切り・通貨・パーセント)で付けるのが道。打ってしまった分は =VALUE が ¥ と桁区切りと % を外して読むので、別列に出して値だけ貼り付ければ戻せる(台帳) |
| 数値を文字列として入力する(先頭の '・表示形式「文字列」) | まだ無い | 007 の先頭ゼロが消えるのは Excel と同じだが、守る側の道具が無い — 先頭の ' の作法は無く(' ごと文字列になる)、表示形式「テキスト (@)」を先に掛けても入力の解釈は変わらない。書式コードでもゼロ詰めは出ない(0000000 を掛けても 7 のまま)ので、ゼロ詰めが要るなら `=RIGHT("0000000"&A1,7)` のように式で作る。Excel 側で文字列として作った番号列は、開いても保存し直しても文字列のまま保たれる — 打ち直したときだけ数に化ける(台帳) |
| 入力が勝手に日付になる(1-2 が 2月1日・遺伝子名 SEPT1 問題) | 違う形 | 入力の解釈は数・TRUE/FALSE・文字の3択だけで日付の当て推量をしないため、この事故は起きない。裏返しに、2026/8/8 と打っても通し番号にはならず文字のままで、=TODAY() も日付書式が自動では付かず素の通し番号のまま出る — 表示形式の「短い日付」などを掛けて初めて暦に見える(文字列の日付は DATEVALUE で通し番号に) |
| CSV 取り込みで番号列が数値化される(列ごとに「文字列」を指定したい) | まだ無い | 取り込みウィザードの控えは文字コード・区切り・置き場所だけで、列ごとの型指定は無い。各欄は入力と同じ解釈を通るため、0 始まりの番号はゼロが落ち、2E3 は数に化ける。データタブの「区切り位置」も割る文字を聞くだけで列のデータ形式は聞かない。守りたい列は plugins の Python(polars の dtype 指定)で読むのが確実な道(台帳) |

## 検索と置換・ジャンプ

検索の板は1枚で、探す言葉と置き換えを続けて聞く — 置き換えを空にすれば
検索だけになる。本家との一番の差は**オプションの展開が無い**こと。検索は
常に「大小を区別する・部分一致・いまのシートだけ」の固定で、Excel の既定
(区別しない)とは逆なので「見つからない」と感じやすい。
詳しくは [calc の手引き](calc-manual.ja.md)。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| 検索(Ctrl+F で文字を探す・次を検索) | 違う形 | 入口はホームの「置き換え」釦か、シートタブ帯の右端の 🔍。板が2枚続けて出る(探す言葉 → 置き換え)。置き換えを空のまま Enter すると検索だけ — いまのセルの次(行→列の順)から探し、末尾まで行ったら頭へ戻る。件数と番地はステータスバーに出て、言葉は次回の板に残るので空 Enter の繰り返しで順に飛べる。Ctrl+F / Ctrl+H は割り当てだけあって calc に受け手が無く、押しても何も起きない |
| 置換(Ctrl+H・すべて置換) | 違う形 | 同じ板で置き換え語まで入れて Enter すると、いまのシート全体を一括置換する(式の中の文字も)。書式は保ち、何カ所替えたかを報告して Ctrl+Z の1手で戻る。範囲を選んでいても効き目はシート全体で、絞り込みで隠れた行も替わる |
| 1件ずつ確認しながらの置換(「置換」釦で1つずつ・「すべて検索」の一覧窓) | まだ無い | 置換は一括のみで、1件ずつの確認送りも一致一覧の窓も無い。空 Enter の検索で当たりを下見してから一括置換し、気に入らなければ Ctrl+Z、が当座の道(台帳) |
| 検索オプション(大文字と小文字を区別する・セル内容が完全に同一なものを検索する) | まだ無い | オプションの展開そのものが無い。検索は常に「区別する・部分一致」の固定(全角半角・かなカナも区別)。セル全体一致だけを拾う切替は無い(台帳) |
| ワイルドカード検索(* ? と ~ のエスケープ) | まだ無い | * ? はただの文字として扱われる。素の検索が常に部分一致なので「〜を含む」は * 無しで足りるが、「A で始まり B で終わる」の型は組めない。式の側も同じで、SEARCH は大小を無視するだけ・COUNTIF/SUMIF の条件も文字は完全一致なので、型で洗うなら FILTER と FIND を組むか、複雑なら データ > Python の正規表現に回す(台帳) |
| 書式で検索・書式を置換(黄色の塗りのセルだけ探す等) | まだ無い | 検索の対象は文字だけで、書式を鍵にする口は無い。置換は元の書式を保つ(書式ごと差し替える道も無い)。色を鍵に並べ替える「選択したセルの色を上に」が隣の仕事の代わりになる場面はある(台帳) |
| 検索場所の切替(シート/ブック全体) | まだ無い | 検索も置換も常にいまのシートだけ。ブック全体を一度に探す切替は無く、シートを替えてもう一度 🔍 を押す(台帳) |
| 検索対象の切替(数式/値/コメント) | 違う形 | 切替は無く、式の打った姿と表示の値の両方を常に探す(=SUM の中の文字も 3.14 の見た目も当たる)。置換が効くのは式の姿の側だけ。セルのコメントの中は探さない |
| 検索方向の切替(行/列・上へ検索) | まだ無い | 順は行→列の固定で、逆向き(前を検索)は無い。末尾まで行ったら頭へ回り込むので、一周すれば全部には会える(台帳) |
| ジャンプ(F5/Ctrl+G・名前ボックスで番地へ飛ぶ) | 違う形 | 名前ボックスに B12・A1:C9・定義済みの名前を打って Enter でそこへ飛ぶ(範囲なら選択になる)。知らない名前ならいまの選択に名前を付けるのも本家の名前ボックスと同じ。ただし F5/Ctrl+G の窓もキーも無く、名前ボックスが受けるのはいまのシートの中だけ — `Sheet2!A1` の形は受けず、名前もシート単位で持つ。他のシートへはタブを踏むか、ハイパーリンクで飛ぶ |
| 条件を選択してジャンプ(Go To Special — 空白セル・定数・数式・条件付き書式・入力規則のセルを一括選択) | まだ無い | 条件でセルを選び取る道具は無い。空白や条件付き書式のセルを目で追うか、FILTER・COUNTBLANK 等の式、または データ > Python で洗い出すのが当座の道(台帳) |
| 参照元・参照先のセルへジャンプ(Go To Special の参照元/参照先・トレース) | 違う形 | 数式タブのトレースが受け持つ — 参照元/参照先のセルを矢印でなく光らせて、件数を報告する(「トレース矢印の削除」で消す)。光った先へ選択が飛ぶわけではない |
| 可視セルだけを選択(Alt+; — 絞り込み中に見えている行だけコピー) | まだ無い | 可視セル選択は無い。絞り込みは見え方だけで保存にも残らない造りなので、見えている行だけ欲しければ FILTER 関数で別の場所にスピルさせるか =PY で抜き出す。「見えている分だけ」の合計・平均・個数はステータスバーの統計が今の正道(台帳) |

## データを他のシステムから持ってくる(Get & Transform / コネクタ)

Excel の答えは Power Query と Copilot コネクタ(基幹のデータをクラウドに
索引させてグリッドへ)。**officework の答えは手元** — データは基幹網の外に
出ない。取り込みは常に「その時の値」で、クエリ定義はブックに残らない。
見本: [問い合わせ台帳](../templates/README.md)・[受注台帳](../sample/README.md)。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| テキストまたは CSV から | 同じ | データタブ「テキスト」→ ウィザード(文字コード・区切り・置き場所をプレビュー3行で)→ 値として流し込む。Power Query を経ない分、手数は少ない |
| 文字コードの指定(化け対策) | 同じ | 自動/UTF-8/Shift_JIS(CP932)/Latin-1。自動は順に試して**使った文字コードを報告**(黙って化けさせない) |
| 区切り文字の指定 | 同じ | 自動/カンマ/タブ/セミコロン/コロン/スペース/その他1文字。小数点・千区切り・テキスト修飾子は控え(台帳) |
| Web から | 違う形 | 組み込み釦は無い。手続き(.py)を `~/.config/office/plugins/` に置き、`@名前 net` でその時だけ網ありの檻で走らせて台帳へ追記。**手続きはブックからは動かない** |

## リンクされたデータ型(株価・地理)

本家のデータ型は、社名や地名をクラウドの照合サービスに送って実体を引く
仕組み。**officework はその仕組み自体を持たない** — データは基幹網の外に
出さない。株価も地理も、要るなら plugins の手続き(.py)で API から
**その時の値**として取り込み、普通の列として持つ。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| セルを株価データ型に変換する | 作らない | 社名をクラウドの照合サービスに送って引く仕組みを持たない(ネイティブファースト)。株価が要るなら plugins の手続きを `@名前 net` で走らせ、証券・市況 API からその時の値として取り込む。取り込みは常に値で、生きた接続はブックに残らない |
| 地理データ型(人口・面積・県庁所在地) | 作らない | 地名を実体に照合するデータ型は株価と同じ理由で持たない。公開統計の API か手元の CSV を plugins の手続きで取り込み、普通の列として持つ — 列がフィールドの代わりになる |
| フィールドの展開(カードを開く・A1.Price の「.」記法) | 作らない | セルが実体を抱えてフィールドを後出しする器そのものが無い。取り込んだ時点で欲しい属性を列に開いて置くのがこの家の形 — 参照は普通のセル参照・VLOOKUP/INDEX/XLOOKUP で足りる |
| FIELDVALUE 関数 | 作らない | 参照先のデータ型自体を作らないため関数も置かない。打てば #NAME? と正直に言う(黙って 0 にしない)。属性の取り出しは取り込んだ列への普通の参照で |
| STOCKHISTORY 関数 | 作らない | クラウドの市況データ供給が前提の関数なので置かない。履歴が要るなら plugins の手続きで yfinance 等を polars で整形し、値の表として流し込む — コードがそのまま手順書になる |
| 通貨ペア(為替レート)のデータ型 | 作らない | 株価と同じ判定。為替 API を plugins の手続きで引き、その時のレートを値として置く。式に効かせるなら取り込んだセルを参照する |
| 株価・地理データの更新(すべて更新) | 違う形 | 生きた接続は持たないが「取り込み直す」道はある — plugins の手続きを `@名前`(網が要るなら `@名前 net`)でもう一度引き、その時の値に置き換える(上の「持ってくる」の「すべて更新」) |
| 開くたび・定時に株価を自動で最新にする | 作らない | 開く=実行はこのソフトの安全の第一原則として存在しない。定時の更新が要るなら pysheet(import 名 office_sheet)を cron から普通の Python として回す — 帳票の外で回すのが型 |
| Wolfram のデータ型・組織のデータ型(Power BI) | 作らない | 組織のデータをクラウドに索引させて引く仕組み自体を持たない — Copilot コネクタと同じ判定。基幹の実体は plugins の手続きが DB・API から直接引く |

## 数式と関数

書き方は同じ — `=` で始め、四則・比較・範囲・$ の効き方まで本家どおり。
知らない関数名は #NAME? になり、**黙って 0 と計算することはない**。
詳しくは [calc の手引き](calc-manual.ja.md)の「式と関数」。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| 数式の入力 | 同じ | 実装済みは約190関数(下の対応表) |
| 相対参照と絶対参照($) | 同じ | コピー・フィル・貼り付けで同じ規則 |
| 関数名の補完・引数ヒント・関数の挿入 | 同じ | 直入力の補完+数式タブの「関数の挿入」(分類→関数)。Shift+F3 のキーだけ未配線(台帳) |
| 名前の定義と管理 | 同じ | 名前ボックス直打ちも可。F3「名前の貼り付け」は無い — 補完で名前が出るのが代わり(台帳) |
| 別シートの参照(Sheet2!A1) | 同じ | `=Sheet2!A1`・`=4月!B2` の直書きがそのまま効く(**2026-08-08 実装** — それまでは #ERROR! だった)。範囲は `=SUM(4月!B1:B5)`、空白や記号を含む名前は `='4月 実績'!B2`。知らないシート名は #REF!(黙って自分のシートと読まない)。値は**その時の値を写す**ので、参照先を直せば再計算で追いつく。`INDIRECT("Sheet2!A1")` の道も従来どおり |
| 串刺し集計(=SUM(Sheet1:Sheet3!A1)) | 同じ | `=SUM(4月:6月!B2)` が効く(**2026-08-08 実装**)。**ブックの並び順**で2枚の間にある全シートを集める(タブを並べ替えれば集める範囲も変わる — Excel と同じ)。逆順に書いても同じ、知らないシート名は #REF! |
| スピル(動的配列) | 同じ | 先客がいれば #SPILL! で潰さない。入れ子・演算も可 |
| 旧来の配列数式(Ctrl+Shift+Enter) | まだ無い | 動的配列は Enter だけで自動スピル。掛け合わせは SUMPRODUCT(台帳) |
| R1C1 参照形式 | 同じ | 詳細設定「参照の形式」。中身は A1 のまま保存され往復は安全 |
| エラー値と IFERROR | 同じ | 伝播の作法も本家どおり。循環だけは独自の #CIRC!(警告+0 ではなくセルに出す) |
| 循環参照と反復計算 | 同じ | 検出して #CIRC!。意図した循環は詳細設定「反復計算」(既定100回・0.001。calcPr と往復) |
| 再計算の自動/手動と F9 | 同じ | F9=全体、Shift+F9=シートだけ |
| 数式の検証(表示・トレース・ウォッチ) | 違う形 | 数式の表示(Ctrl+`)は同じ。トレースは矢印でなく該当セルが光る。ウォッチは独立の窓でなく下の帯 |
| 構造化参照(=Table1[金額]) | 同じ | `=SUM(売上表[金額])` が効く(**2026-08-08 実装**)。データ本体だけを指し、見出しと合計行は入らない。同じ行は `[@金額]`(表の中でだけ。外からは `売上表[@金額]`)。知らない表・列は #REF!。`[[#見出し],[列]]` の入れ子の形はまだ受けない(式のエラーになる — 台帳に控え) |
| =PY(Python in Excel) | 違う形 | クラウドでなく**手元の檻で無料**。実行は データ > Python の @計算 のときだけ — 開いても再計算でも走らない。Excel で開くと #NAME? だが値は残る |

## 関数対応表

無い物を隠さない。無い名前を書けば #NAME? と正直に言う。一覧と分類は
数式タブの「関数の挿入」(本家と同じ形)にもある。

| Excel の関数 | ある? | 代わり・備考 |
|---|---|---|
| VLOOKUP・HLOOKUP・XLOOKUP・LOOKUP・INDEX・MATCH | ある | **完全一致のみ**(MATCH の照合の型は 0 だけ、近似一致は無い)。昇順前提の「以下で最大」は LOOKUP が受け持つ |
| XMATCH・SORTBY | ない | MATCH・SORT で足りる範囲 |
| SUMIF・COUNTIF・AVERAGEIF・SUMIFS・COUNTIFS・AVERAGEIFS・MAXIFS・MINIFS・SUMPRODUCT | ある | 同じ書き方 |
| IF・IFS・SWITCH・CHOOSE・AND・OR・NOT・IFERROR・IFNA | ある | IF は選ばなかった側のエラーを踏まない |
| TODAY・NOW・DATE・DATEDIF・EDATE・EOMONTH・WORKDAY・NETWORKDAYS・YEARFRAC・WEEKNUM | ある | 祝日リストの引数も渡せる |
| LEFT・RIGHT・MID・FIND・SEARCH・SUBSTITUTE・TRIM・TEXT・TEXTJOIN・CONCAT | ある | TEXT の書式コードも通る |
| REPLACE(位置指定の置換) | ない | SUBSTITUTE か LEFT&MID の組み合わせで(在庫候補) |
| FILTER・SORT・UNIQUE・SEQUENCE・TRANSPOSE | ある | スピルする5つ |
| RANDARRAY・VSTACK/HSTACK・TAKE/DROP・TOCOL 等の拡張スピル | ない | (在庫候補) |
| LET | ある | `=LET(x, SUM(A1:A9), x/COUNT(A1:A9))` — 途中結果に名前を付けて二度計算しない(**2026-08-08 実装**)。入れ子も可、名前は LET の中だけ |
| LAMBDA | ない | 本家は「名前の定義」に式を入れて呼ぶが、うちの名前は**範囲しか持てない**ので見送り(台帳に理由つきで控え)。同じ役目は =PY の Python 関数([Python の手引き](python-manual.ja.md)) |

| DSUM・DAVERAGE・DGET(D 系) | ない | SUMIFS・AVERAGEIFS・FILTER で — 本家でも今は IFS 系が推奨の道(在庫候補) |
| PMT・PV・FV・NPER・NPV・IRR・RATE | ある | IRR・RATE は本家と同じく反復解 |
| SUBTOTAL・AGGREGATE | ある | **101〜111 は手で隠した行(グループの畳みを含む)を飛ばす**(2026-08-08 実装。1〜11 は全部数える — Excel と同じ)。ただし**絞り込みで隠れた行はまだ数に入る**(絞り込みは画面側の状態で、式の評価器から見えない — 台帳に控え)。見えている行だけの合計・平均・個数は、下のステータスバーの統計が絞り込みを尊重する |
| PHONETIC・ASC・JIS・DBCS・LENB/LEFTB/RIGHTB/MIDB・DATESTRING・YEN | ある | 日本語の定番一式(和暦・全角=2 の数え方) |
| =PY(セル関数を Python で) | ある(こちらが先) | 手元の檻・無料。ブックが運べる Python はこの関数(UDF)だけ |

## アウトライン(グループ化)

作法の骨は Excel どおり(グループ化・詳細の非表示/表示・小計)。違うのは画面 —
左端のアウトライン余白(縦棒とレベル番号の釦)は無く、+/− の丸印がかたまりの
直後の**行見出し**に出る。深さと畳みは xlsx と往復するので、畳んだ台帳は
畳んだまま渡る。詳しくは [calc の手引き](calc-manual.ja.md)の「データ」。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| 行のグループ化(データ > グループ化) | 同じ | 行の見出し(番号)を撫でて選び、データタブの「グループ化」。深さ+1 で、Ctrl+Z の1手で戻る |
| 列のグループ化(行か列かを選ぶダイアログ) | 違う形 | 行か列かを聞かない — 選択の形で決まる。列見出しから列をまるごと選んでいれば列、それ以外は選択の行に効く。列も畳み開きできるが +/− の丸印は行にしか出ないので、列はリボンの「詳細の非表示/表示」で |
| +/− のアウトライン記号・レベルバー | 違う形 | 左端のアウトライン余白は無い。かたまりの直後の行の見出しに +/− の丸印が出て、押すだけで畳み開き(集計行が下、の形) |
| 詳細の非表示・詳細の表示 | 同じ | データタブの2釦。選択が無ければカーソルの行が属するグループのひとつながりに効く |
| グループの入れ子(最大8レベル) | 同じ | もう一度グループ化すると深さが増え、outlineLevel 1〜7(ECMA-376 の上限)で頭打ち。本家の「最大8レベル」は基底+7段の数え方で同じ意味 |
| レベル番号のボタン(1 2 3 … の一括開閉) | 作らない | +/− の丸印と「詳細の非表示/表示」で足りるため控え(2026-08-07) |
| アウトラインの自動作成(数式の向きから) | まだ無い | 数式を読んで自動で組む釦は無い。畳んで合計を見せたいなら「小計」が代わり(台帳) |
| アウトラインのクリア(一括で消す) | 違う形 | 一発で全部消す釦は無い。「グループ解除」が1段ずつほどき、深さ0になった行・列は畳み(hidden)も一緒に消える — 深い入れ子は段数ぶん押す |
| 小計による自動アウトライン | 同じ | データタブの「小計」が区切りごとに =SUM の小計行と総計行を入れ、明細だけをグループ化する。畳むと小計と総計だけが残る。全部まとめて Ctrl+Z の1手 |
| グループと畳んだ状態の保存 | 同じ | 深さは outlineLevel、畳みは hidden と往復。Excel で開けば普通のアウトラインに見える。中身の無い行の深さも消えない(往復試験あり) |
| 畳んだ行・列の印刷 | 同じ | 畳んだ行・列は印刷(PDF)にも出ない。見せたい姿で畳んでから刷ればよい |
| 行の挿入・削除でずれないか | 同じ | 行を挿しても消しても、グループの深さと畳みは行に付いてくる(試験つき) |

## データの統合と分析の道具

Excel の答えは 統合ダイアログ・データモデル(Power Pivot)・分析ツールアドインの
3つ。**officework の答えはどれも polars(Python)** — ブックの中に分析エンジンを
積まず、結合・集計・検定は データ > Python か plugins の手続きが受け持つ。
帳票は結果の置き場で、重いデータと難しい計算はその外に置く。
詳しくは [Python の手引き](python-manual.ja.md)。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| 位置による統合(同じ配置の月次シートを足し上げる) | まだ無い | 統合の釦は無い。配置が同じなら `=4月!B2+5月!B2+…` の手組みで足りる。枚数が多ければ データ > Python で polars に足させる(台帳に未記載 — 在庫候補) |
| 項目による統合(上端行・左端列の項目名で合わせる) | まだ無い | 無い。`=SUMIF(4月!A2:A50,$A2,4月!B2:B50)+…` とシートぶん重ねる。並びが揃わない・枚数が多いなら polars の concat と group_by が確実で、表記ゆれもそこで直せる(在庫候補) |
| 統合の集計方法(個数・平均・最大・最小・標準偏差) | まだ無い | ダイアログが無いので選ぶ場面も無い。COUNTIFS・AVERAGEIF(S)・MINIFS・MAXIFS に替えるだけ。標準偏差だけは …IFS 形が無い — polars なら agg の指定を替えるだけで全部賄える |
| 串刺し集計(=SUM(Sheet1:Sheet3!B2)) | 同じ | ブックの並び順で2枚の間の全シートを集める(**2026-08-08 実装**。上の「数式と関数」にも既出) |
| 「元データとリンクする」(統合結果を追従させる) | まだ無い | 統合機能ごと無いが、手組みは式なので元を直せば再計算で追いつく — リンク付き統合と同じ性質。polars の道は「その時の値」なので、元が変わったら回し直す(ピボットの「更新」と同じ考え方) |
| 別ブックの範囲を統合に含める(=[Book1.xlsx]…) | 作らない | 生きた外部参照は張らない — リンク切れ・古びた参照の帳票を作らないため。他ブックは「外部リンク」で値のシートとして取り込んでから、同一ブック内の道に載せる |
| 複数ブックのデータを1つにまとめる | 違う形 | Power Query や統合でなく、データタブ「外部リンク」が相手ブックの全シートを式抜きの値として取り込む(シート名に元ブック名が付き、同名は避ける)。以後は同一ブックの話 |
| 複数のワークシート範囲からピボット(旧ウィザード) | まだ無い | ピボットが取るのは1つの表(選択範囲か、カーソルの表の自動検出)だけ。データ > Python で polars の concat により縦に積んで1枚にしてから挿す |
| 明細シートを縦に積む(月次明細の結合と重複の始末) | まだ無い | 積む釦は無い。データ > Python で各シートの values() を集めて concat、重複は unique か group_by で始末して書き戻す。定型業務なら plugins の .py に控えて回す。手作業ならコピペと「重複削除」 |
| データモデルに追加する(ブック内データモデル) | 作らない | ブックの中に分析エンジンを積まない。分析・集計は polars に回すのが分業の線で、ピボット自体が裏方の polars で表から直接組まれる — 中間の入れ物を持たない |
| リレーションシップ(2つのテーブルをキー列で結ぶ) | 違う形 | polars の join を データ > Python か plugins の手続きで書く。1列を引き当てるだけなら VLOOKUP・XLOOKUP(完全一致のみ)でも足りる |
| 複数テーブルにまたがるピボットテーブル | 違う形 | ピボットの元は常に1枚の表。先に join で1枚にまとめてシートに置き、その表に組み込みピボットを挿す |
| メジャーの作成(DAX 式) | 違う形 | DAX という別言語は積まない — 計算の言語は Python 一本。独自集計は polars の group_by/agg で書くか、=PY の UDF に切り出す |
| 「個別のカウント」(distinct count) | まだ無い | 組み込みピボットの集計は合計・平均・個数・最大・最小の5種だけ。当座は polars の n_unique を データ > Python で(台帳) |
| 計算列(DAX の計算列) | 違う形 | 表の右に普通の式の列を足す(相対参照+フィルで全行へ)。polars の with_columns でも同じ仕事 |
| KPI の定義(目標との対比・信号アイコン) | まだ無い | 専用の道具は無い。式の列で達成率を出し、条件付き書式のアイコンセット(xlsx と往復)で信号を付けるのが近い道 |
| 数百万行をモデルに読み込んで分析 | 違う形 | 大きいデータはブックに入れない。plugins の手続きで polars が CSV や DB を直接読み、集計した結果だけをシートへ置く — 帳票は結果の置き場、データ本体はファイル/DB 側 |
| GETPIVOTDATA・CUBEVALUE | 違う形 | 関数そのものは無く、書けば #NAME? と正直に言う。ピボットの結果はただのセルとして置かれるので、普通のセル参照や XLOOKUP でそのまま引ける |
| 日付テーブル(月・四半期・年の軸で集計) | 違う形 | 日付テーブルは作らない。ピボットのグループ化(月/四半期/年・数の幅)が同じ仕事をし、読めない日付は黙って落とさずそのまま残す |
| タイムインテリジェンス(前年比・累計) | 違う形 | ピボットの「計算の種類」に 累計・前との差 が入った(**2026-08-08 実装**)。前年比のような期をまたぐ比較は無く、polars の shift を データ > Python で |
| Power Pivot 入りのブックを開く・保存する | 違う形 | モデルは画面に出ないが原文のまま持ち越す — 保存しても壊れず、Excel で開き直せば元通り。Excel のピボットはシート上の値として見えるが、officework から「更新」はできない(更新が効くのは自前の joPivot だけ) |
| 分析ツールアドインの有効化(「データ分析」釦を出す) | 違う形 | アドインを入れる手続きそのものが無い。統計・予測は最初から データ > Python(polars・scipy・statsmodels)が指定の道 |
| ヒストグラム | 違う形 | 専用ダイアログは無い。階級の列を作って =COUNTIFS で数え、挿入のグラフ(縦棒)で描く。まとめてやるなら データ > Python で度数を書き戻す |
| FREQUENCY(配列で一気に度数分布) | まだ無い | 関数が無い。当座は COUNTIFS で同じ度数表が組める(台帳に未記載 — 在庫候補) |
| 移動平均 | 違う形 | 専用ツールは無い。=AVERAGE(A1:A3) のような窓の式を書き、ホームの「フィル」で下へ写す。長い系列は polars の rolling。グラフに近似曲線を載せる道は無い |
| 回帰分析(傾き・切片・予測値・相関) | 違う形 | 出力一式のダイアログは無いが、単回帰は関数で足りる — SLOPE・INTERCEPT・FORECAST(.LINEAR)・CORREL。決定係数は CORREL の2乗で(RSQ・STEYX は無い)。p値・残差まで要る回帰レポート相当は statsmodels |
| LINEST・TREND(重回帰・配列の当てはめ) | まだ無い | 関数が無い。重回帰は データ > Python の statsmodels が指定の道(台帳に未記載 — 在庫候補) |
| 乱数を出す(RAND・RANDBETWEEN) | 同じ | そのまま通じる。再計算のたびに変わる揮発の扱いも同じ。RANDBETWEEN の上下逆は #NUM! で本家どおり |
| 分布を指定した乱数発生(正規・二項) | 違う形 | 乱数発生ダイアログも NORM.INV 等の分布関数も無い。データ > Python で scipy・numpy の乱数を作りセルへ書き戻す(複製の上で回り、Ctrl+Z 一手で戻る)。分布関数群は台帳に未記載 — 在庫候補 |
| RANDARRAY(乱数を範囲へ一気に) | まだ無い | 無い。台帳に拡張スピルの残件として記載済み。当座は列を選んで =RAND() を入れフィルで埋める(下方向のみ) |
| 記述統計(平均・中央値・標準偏差の一覧表) | 違う形 | 一覧を吐くダイアログは無いが、関数は一通りある — MEDIAN・MODE・STDEV(P)/VAR(P)(.S/.P の新名も)・PERCENTILE・QUARTILE・LARGE・SMALL。尖度・歪度(KURT・SKEW)・GEOMEAN は無い(在庫候補)。一枚の表で欲しければ polars で組んで書き戻す |
| 順位と百分位数 | 違う形 | ツールでなく関数で — RANK(.EQ/.AVG)・PERCENTILE・QUARTILE。同値の扱い(EQ は同順位・AVG は順位の平均)も本家どおり |
| 相関(多列の相関行列) | 違う形 | 2列なら =CORREL。行列を一気に出すダイアログは無く、データ > Python(polars)で作って書き戻す。共分散(COVAR 系)は無い(在庫候補) |
| t検定・F検定・分散分析・カイ二乗検定 | 違う形 | 検定の関数(T.TEST 等)もダイアログも無い。検定は データ > Python の scipy.stats・statsmodels が指定の道 — 網の無い檻の中で、機械に入っていれば使える(関数群は台帳に未記載 — 在庫候補) |
| 指数平滑・FORECAST.ETS・予測シート | まだ無い | 予測シートは台帳に残件。直線の予測(FORECAST/FORECAST.LINEAR)だけはある。指数平滑・季節つき予測は当座 データ > Python の statsmodels で |

## 条件付き書式

対応する型は xlsx と往復し、読めない型は**開くときに報告して落とす**(黙って
落とさない)。自前で掛ける書式は薄緑・薄赤などの決め打ちで、書式選択
ダイアログは無い。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| セルの強調表示(大きい/小さい/間/文字を含む) | 同じ | ホームか右クリックの一覧から。しきい値・文字を打つだけ |
| 重複する値・一意の値 | 同じ | duplicateValues/uniqueValues と往復 |
| 上位/下位 N 項目 | 同じ | top10 と往復 |
| 上位/下位パーセント | まだ無い | Excel の % 規則は「保存で失われる」と報告して落とす(台帳に控え) |
| 平均より上/下 | 同じ | 標準偏差いくつ分の変種は無い |
| データバー | 同じ | Excel の色は読んで保つ。自前は青の決め打ち |
| カラースケール(2色/3色) | 同じ | 百分位は最小/最大の直線で近似 |
| アイコンセット | 同じ | iconSet 名を保って往復。区切り値(cfvo)の指定画面は無い |
| 数式ルール | まだ無い | 1行おきの縞が目的なら表の「縞模様の行/列」が同じ仕事(台帳に控え) |
| 日付のルール(timePeriod) | まだ無い | 台帳に控え |
| 空白・エラーのルール | まだ無い | 台帳に控え |
| ルールの管理 | 違う形 | 一覧+「移動/消す」。編集・優先順位・プレビューは無く、**消して掛け直すのがこの家の道**。重なりは後掛けが上書き |
| ルールのクリア | 同じ | 何本消したかを言う |
| 印刷に出るか | 違う形 | 塗り・文字色は紙にも効く。**バー・スケール・アイコンは画面だけ**(台帳に控え) |

グラフは選択範囲から matplotlib が描いて**画像として**浮かぶ — Excel の
グラフ部品ではない。挿した時の値の絵で、データには追随しない。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| グラフの挿入 | 違う形 | 挿入タブ「グラフ」→ 縦棒を画像で。日本語フォントは機械の物を登録(豆腐にしない) |
| おすすめグラフ | 違う形 | 釦はあるが勧めるのは常に縦棒 — データを見る知恵は積んでいない |
| グラフの種類(円・折れ線…) | 作らない | 縦棒のみの割り切り([台帳](guide-tsukiawase-2.ja.md)の方針の節) |
| 種類の後から変更・データの選択・自動更新 | 作らない | 画像なので無い。古い絵を Del で消し、選び直してもう一度挿す |
| 要素の編集(タイトル・軸・凡例) | 作らない | 凡例だけは系列2つ以上で自動 |
| グラフの移動・リサイズ・削除 | 同じ | セルの錨+px ずらしで xlsx と往復 |
| Excel のグラフ入りブックを開く | 違う形 | 画面には描かないが**原文のまま持ち越す** — 保存しても壊れず、Excel で開き直せば元通り |
| スパークラインの挿入 | 同じ | 数の範囲を選んで挿入タブ。置き場所はいまのセル |
| 種類(折れ線・縦棒・勝ち負け) | 同じ | 3種。xlsx へは棒ごとの図形で書くので Excel でも同じ形に見える(往復試験つき) |
| 色・マーカー・軸の設定 | まだ無い | 固定の緑一色(台帳) |
| スパークラインの削除 | 違う形 | 右クリックのクリアでなく、図形と同じくクリックして Del |
| 元データへの自動追随 | 作らない | 挿した時の値の図形。消してもう一度挿す(台帳の方針) |

## ハイパーリンク

リンクは本家の大きなダイアログではなく板1枚(URL → 表示テキストの2段)で付ける。既定はひとつ逆で、**開くのは Ctrl+クリック**、ただのクリックはセルの選択 — うっかり飛ぶ事故が起きない側に倒してある。打った URL が勝手にリンクになることもない。詳しくは [calc の手引き](calc-manual.ja.md)。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| ハイパーリンクの挿入(リンクのダイアログ) | 違う形 | 挿入タブか右クリックの「ハイパーリンク」で板が開き、URL か `#シート名!B5` を打つ。本家の4区分(既存ファイル/ドキュメント内/新規作成/メール)の大きなダイアログではなく、板1枚+続きの表示テキストの板という2段の作りである。リンクのあるセルは青字になり、カーソルを置くと URL がヒントに出る |
| Ctrl+K でリンクを付ける | 同じ | 同じ板が開く。本家と同じキーである |
| リンクを開く(クリックで飛ぶ/開かずにセルだけ選ぶ) | 違う形 | 開くのは Ctrl+クリック。ただのクリックはセルの選択である — 本家の「うっかり飛ぶ」「長押しで選択」問題が起きない向きに既定を逆にしてある。外の URL は OS の既定ブラウザに渡す |
| ブック内の場所へのリンク(このドキュメント内) | 違う形 | URL の代わりに `#シート名!B5`(`#B5`・`#A1:C9` も可)と打つ。Ctrl+クリックでそのシート・セル・範囲へ跳ぶ。シート一覧のツリーから選ぶ形ではなく、場所を文字で書く形である |
| リンクの表示テキスト(セルに見せる文字) | 違う形 | URL の板の続きに表示テキストの板が開き、セルへ入る。空 Enter ならセルの中身はそのまま。ダイアログの欄ではなく続きの板という形である |
| 既存のハイパーリンクの編集(リンク先の変更) | 同じ | リンクのあるセルでもう一度 Ctrl+K(または右クリック)。いまの URL が入った状態で板が開くので、直して Enter |
| ハイパーリンクの削除(1つ外す) | 違う形 | リンクの板を開き、空にして Enter で外れる。右クリックの「ハイパーリンクの削除」という専用項目ではない |
| 範囲のハイパーリンクをまとめて消す(クリア) | 同じ | 消去の選択肢に「ハイパーリンク」がある。選んだ範囲のリンクだけ消し、値や書式は残る。何個消したか状態行で言い、Ctrl+Z で戻せる |
| URL を打つと勝手にリンクになるのを止める | 作らない | そもそも勝手なリンク化をしない — 打った URL はただの文字列のまま。オートコレクト機構自体を持たないので、止める設定を探す必要が無い。リンクにしたければ Ctrl+K で明示に付ける |
| HYPERLINK 関数 | 違う形 | `=HYPERLINK(リンク先, [別名])` は使え、別名(無ければリンク先)を表示する。ただし式からは飛ぶ仕掛けが付かない — 跳びたければ Ctrl+K でセルにリンクを付ける(飛ぶ仕掛けはセルのリンクの仕事) |
| スクリーンチップ(ポイント時のヒント文字) | 作らない | 板1枚の作りに合わないため見送り(台帳に理由つきで控え)。代わりにカーソルのセルではリンク先 URL 自体がヒントに出る |
| 定義された名前へのリンク | まだ無い | `#名前` と打っても跳べない — リンク先の解釈は番地だけで、定義済みの名前を引かない。当座は `#シート名!A1:C9` と番地で書くか、名前ボックスに名前を打って飛ぶ(台帳) |
| メールアドレス・手元のファイルへのリンク | 違う形 | 専用の「電子メールアドレス」「既存のファイル」欄は無い。板に `mailto:` やファイルの場所をそのまま打てば、`#` で始まらないものは何でも OS の既定に渡して開く。「新規作成ファイルへのリンク」に当たる道は無い |
| Excel で付けたリンクを壊さない(xlsx との往復) | 同じ | 外部 URL は External として、ブック内リンクは location として読み書きする。Excel で付けたリンクは開いても保存しても生きる |

## 入力規則(データの入力規則)

本家と同じ3タブの板(設定・メッセージ・エラー)。家訓は「**判定できない
規則で入力を止めない**」— 読めない規則は保持して素通しする。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| ドロップダウンリスト | 同じ | 許可=リスト、直書きか範囲参照。セル右下の ▾ から選ぶ |
| 元の値をセル範囲に | 同じ | 参照先を書き換えれば追従。別シート参照は解決できず**制限なしとして通す** |
| 整数・小数の範囲 | 同じ | 比較8種。全角の数字は半角にならして受ける |
| 文字列の長さ | 同じ | 比較8種 |
| 日付・時刻 | まだ無い | 既存の規則は「このまま保持」で壊さず持ち越し、判定はせず素通し(台帳) |
| ユーザー設定(数式) | まだ無い | 同上(台帳) |
| 入力時メッセージ | 違う形 | 吹き出しでなく画面下の状態行に出る。xlsx と往復 |
| エラーメッセージ(停止・警告・情報) | 違う形 | 停止=堰き止め(Esc で戻す)、警告・情報=通した上で「合いませんが、通しました」。再試行ダイアログは出さず状態行で言う |
| 空白を無視 | 同じ | allowBlank と往復 |
| セル内 ▾ の表示/非表示 | 同じ | showDropDown と往復 |
| 同じ規則のセルへまとめて適用 | 同じ | 板のチェックで範囲据え置きの差し替え |
| すべてクリア | 違う形 | 専用釦は無いが、許可を「すべての値」にして OK で外れる |
| Alt+↓ でドロップダウン | 違う形 | 右クリック「ドロップダウンリストから選択する」か ▾。規則が無いセルでも同じ列の値が候補に。キーそのものは無い |
| 無効データのマーク(丸囲み) | まだ無い | 後から規則に合わなくなった値を洗う道具は無い(台帳に未記載 — 在庫候補) |
| Excel の規則の往復 | 同じ | 知らない種類も落とさず持ち越す |

## What-If 分析

「What-If 分析」の束ねメニューは無く、データタブに**ゴールシーク**と
**ソルバー**が直に並ぶ(アドインの登録は要らない)。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| ゴールシーク | 違う形 | 「セル=目標値」→「変えるセル」の2段の問い。探索は表の複製の上(本物を汚さない) |
| 結果の OK/キャンセル | 違う形 | 確認窓は出ない。すぐ書いてステータスバーで報告、Ctrl+Z の1手で戻る |
| 解が見つからないとき | 同じ | 正直に言い、中途半端な値を書き込まない |
| ソルバー(最大/最小/値・変数・制約) | 同じ | 小窓で決めて「解を求める」。Ctrl+Z で戻る |
| GRG 非線形・エボリューショナリー | 作らない | 解法は単体法 LP ひとつ。線形でなければ正直に断る(台帳の方針)。非線形は =PY・plugins から scipy を直に |

| データテーブル(感度表) | 違う形 | データタブ「データテーブル」で 列の入力セル → 行の入力セル(空 Enter = 1変数)を聞く(**2026-08-08 実装**)。表の形は Excel と同じ(1変数=左の列に入力値・上の行に式、2変数=角に式)。本家の TABLE() の配列式ではなく**その時の値**を埋めるので、入力を直したらもう一度押す |
| シナリオマネージャー | まだ無い | 場合ごとの入力は別シート・別ブックで手差し替え(台帳に未記載 — 在庫候補) |
| 予測シート | まだ無い | FORECAST 関数はある。=PY からは statsmodels・polars で(台帳に未記載 — 在庫候補) |

## マクロと自動化(VBA → Python)

- VBA は**意図して積まない** — 「開く=実行」の30年の穴を持ち込まない
  ([設計](sekkei/python.ja.md))。役目は Python:
  [Python の手引き](python-manual.ja.md)
- **ブックが運べるのは =PY の関数だけ**。手続きは
  `~/.config/office/plugins/` に自分で置いた .py だけが動く —
  受け取ったファイルは実行の起点になれない(2026-08-08 確定)

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| マクロの記録 | 違う形 | 記録釦は無い。日本語で AI に頼んで Python を書かせ、檻で試す(申し送りのコピペ枠が手引きに)。納得したら plugins へ、以後 @名前 |
| VBA・Visual Basic Editor | 作らない | 上記([設計](sekkei/python.ja.md)) |
| .xlsm の VBA 資産 | 違う形 | olevba で取り出し → AI に申し送りと渡して Python へ → 同じ入力で答え合わせ。.xlsm を直接開く口も無い |
| マクロのセキュリティ設定(3択・黄色い帯) | 作らない | 自動実行が無く実行は常に明示+檻なので、選ばせる場面が生じない |
| Workbook_Open / Auto_Open | 作らない | 開く=実行は存在しない — このソフトの安全の第一原則 |
| Worksheet_Change 等のイベント | 作らない | 入力規則・条件付き書式+明示の @名前・@計算 で組む |
| 個人用マクロブック(PERSONAL.XLSB) | 違う形 | `~/.config/office/plugins/` がその置き場 — どのブックからでも @名前 |
| ボタン・図形にマクロ割り当て | 作らない | 「押した=実行」を帳票に仕込む口は作らない(場所は灰色で確保) |
| 自作のワークシート関数(Function) | 違う形 | Python の def を @save でブックに載せ、=PY("関数名", …) で呼ぶ。2次元の返り値は右下へスピル |
| Office スクリプト+Power Automate | 違う形 | 予定実行は pysheet(office_sheet)を cron 等から普通の Python として回す |
| MsgBox・InputBox・ユーザーフォーム | 違う形 | 窓は出さない。print はステータスバーへ、入力は帳票のセル+入力規則 — 帳票そのものが UI |
| xlwings・COM 自動化 | 同じ | officework の1行差し替え。@xw.func / Book.caller() は未対応(同じ役目は plugins) |
| Web・基幹 API との通信 | 違う形 | 檻は既定で網なし。`@名前 net` とその場で打った時だけ通り、**許可はどこにも保存されない** |

## AI(Copilot に相当するもの)

AI はコードと文面を書く係。**実行は常に人の明示の操作+檻**で、AI の反映は
必ず控えを取ってから — どれも Ctrl+Z の1手で戻る。既定の宛先は手元の
モデルで、データはネットワークの外に出ない。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| 「表にして」 | 同じ | AI タブ「表にする」。置き場に中身があれば断る |
| 数式を書いてもらう | 違う形 | 「頼む」に用件を打つ。1セルへの1式が単位(数式列の一括追加ではない) |
| データの要約 | 違う形 | 2〜4文がカーソルのセルのコメントに付く(保存で xlsx にも残る) |
| インサイト(おすすめグラフ・ピボットの提案) | まだ無い | グラフもピボットも自分の手で — AI 無しで成立する道(台帳に未記載 — 在庫候補) |
| 自然言語で操作指示(「金額順に並べて」) | まだ無い | AI の返事は表・式・コメントの3形だけで画面の操作はしない(在庫候補) |
| マクロを書いてもらう | 違う形 | calc の AI タブに釦は無い(writer にはある)。「AI への申し送り」を貼って台本を書かせ、plugins に置いて自分で実行 |
| VBA の AI 移行 | 違う形 | 一発釦はまだ。olevba → 申し送り → 檻で答え合わせ、の型が手引きに |
| Copilot コネクタ | 作らない | AI とデータ搬入を束ねない(「持ってくる」の節) |
| ライセンス・サインイン | 違う形 | 無い。宛先は 手元(既定)→ Claude 定額 → Claude API(鍵は環境変数のみ)。使えなければ理由を言って断る |
| プライバシー | 違う形 | 外に出すのは宛先で自分が明示して選んだ時だけ。鍵がブックに入ることは無い |
| 文面調整(書き直す・敬語・翻訳) | 同じ | 文字のセルだけ置き換え、数字と式は触らない |
| 続きのデータを埋める | 同じ | 「続きを書く」。「AI の当て推量なので、よく確かめて」と言う |
| ふりがな列 | 違う形 | 1列選ぶと読みが右隣に。PHONETIC(入力履歴)と違いモデルが読みを付ける |

## 印刷・ページレイアウト

**印刷=PDF**(画面=紙)。ファイル > 印刷 で紙面がそのまま PDF になり、
プリンターへはその PDF を OS の印刷で出す。効かせた設定はステータスバーで
報告する。詳しくは [calc の手引き](calc-manual.ja.md)の「印刷と PDF」。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| 印刷(Ctrl+P) | 違う形 | ファイル > 印刷 → PDF。Ctrl+P のキーは無い(台帳) |
| 印刷範囲の設定・解除 | 同じ | Print_Area と往復 |
| 複数の印刷範囲 | まだ無い | 常に1件。xlsx に複数あれば最初の1件+「残り n 域は出せません」と正直に(台帳) |
| 改ページ(横)の挿入・削除 | 同じ | rowBreaks と往復。「すべて解除」は無い — 1本ずつ |
| 縦の改ページ(列の区切り) | まだ無い | 台帳に残件 |
| 改ページプレビュー・境界の点線 | まだ無い | 釦は灰色。仕上がりは PDF に出して確かめる(台帳) |
| 拡大縮小印刷(%) | 違う形 | 100→90→80→70→50% の循環。任意%は打てないが xlsx と往復 |
| 横1×縦N ページに収める | まだ無い | %を落として収める(台帳) |
| ヘッダー/フッター(&P/&N) | 同じ | 6区分。日付・画像・奇偶別などは控え。理解しない &コードは化けさせず落とす |
| タイトル行の繰り返し | 同じ | Print_Titles と往復。タイトル列(左に繰り返す)は無い |
| 枠線・見出しの印刷 | 同じ | printOptions と往復 |
| 用紙・向き・余白 | 違う形 | A4/A3/B4/B5/A5(B は JIS)。余白は3択の循環、任意値は打てない |
| PDF で保存 | 違う形 | 「印刷」がそれ — 一手で済む |
| 横に大きい表の複数ページ | 同じ | 紙の幅で列を束に割り、**縦 → 横**の順で刷る(Excel の既定と同じ)。束の頭には列名の見出しとタイトル行も出る(**2026-08-08 実装**)。1列だけで紙より広い列は割りようが無いので切れ、その本数を状態行で言う |

## 配る前に — 校正・検査・型紙

配る前の仕事は三つ — 誤りを見る、隠れた物を洗う、次の人へ型紙で渡す。校正は calc にはまだ無く(writer なら画面下の「スペル」釦から)、一括のドキュメント検査も無い — 見る場所はファイルタブの情報パネル・表示タブ・セルのコメントと散っている。型紙は .xltx ではなく普通の xlsx を共有フォルダに置いてコピーする形。ただし**保存がそもそも名前を書き足さない**ので、Excel でオプトインで消していた物は既定で入らない。詳しくは [calc の手引き](calc-manual.ja.md)。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| スペルチェック(F7・校閲タブ) | まだ無い | calc にはリボンの釦もキーの割り当ても無い。writer なら掛けられるが、置き場は校閲タブではなく**画面下のステータスバーの「スペル」釦** — 英語は辞書、日本語はローカルのモデルが見る。calc への接続は writer と共通化できる控え(台帳) |
| 日本語の誤りも見てほしい(本家は英単語だけ) | 違う形 | 日本語の誤りの正体は綴りでなく誤変換(以外/意外)・表記ゆれ・送り仮名で、辞書では捕まらないから、ここではローカルのモデルに聞く。writer の「スペル」釦と、画面なしの `office-spell` コマンドで使える(基幹網の外に出ない)。繋がらなければ「校正できません」と出す — 黙って「指摘なし」にはしない |
| オートコレクト(文頭を大文字に・先頭2文字・CapsLock の直し) | まだ無い | 台帳に控えとして載るが、「黙って別の意味にしない」がこの家の流儀なので、入るとしても勝手に直す形にはなりにくい。大文字小文字を変えたいときはホームの「changecase」で明示に掛ける |
| オートコレクトに自分の項目を登録((c)→© など) | まだ無い | 登録の画面も置換の仕組みも無い。オートコレクト一式が calc に無いため、その上に乗るユーザー定義もまだ無い(台帳) |
| 数学オートコレクト・入力中の自動フォーマット | まだ無い | 本家の3タブに当たる箇所が calc に無い(台帳)。記号は挿入タブの「記号」から明示に入れる |
| URL を打つと勝手にハイパーリンクになる | 違う形 | 勝手にはリンクにならない — リンクは Ctrl+K か挿入タブで明示に張り、板に打って確定した分だけが付く。自動リンク化が無いので「止める設定」を探す場面も生まれない(上の「ハイパーリンク」) |
| 辞書に単語を追加(固有名詞・社名が誤り扱いされる) | 違う形 | ユーザ辞書はファイルで持ち、環境変数 `OFFICE_DICT_USER` で指す(hunspell と同じ受け方)。一度判定した語は覚えて二度聞かない。指摘の場から「辞書に追加」する釦はまだ無く、設定画面にも辞書の欄は無い |
| 校正言語の設定(文書ごとに辞書の言語を選ぶ) | 違う形 | 言語は選ばせず、1つの窓口が中身で振り分ける — 英語は辞書、日本語はモデル、混在した文書は両方を掛ける(日本語に英単語が混ざるのは普通だから)。言語を切り替える設定画面は無い。詳細設定の「言語」はリボンの文言用で校正とは別 |
| 類義語辞典(シソーラス) | まだ無い | 掛ける道は無く、台帳にも未記載。言い換えなら AI タブの「書き直す」「敬語にする」「やさしく」が文字のセルだけを置き換える別の道としてある |
| 関数名を小文字で打っても通る(=sum → =SUM) | 違う形 | 小文字で打った関数名もそのまま解釈されて計算される。ただし打った式の文字面は直さない — `=sum(A1:A3)` は `=sum(A1:A3)` のまま残る(本家のように書き換えない) |
| ドキュメント検査(隠しデータ・個人情報の一括洗い出し) | まだ無い | 一括で洗い出す検査は無い。見る場所は散っている — プロパティはファイルタブの情報パネル、隠しシートは表示タブ、コメントはセルごと。個々の部品は下のとおり見に行けるが、束ねる釦が無い(台帳に未記載 — 在庫候補) |
| ブックのプロパティ(作成者・タイトル・タグ・件名・コメント) | 同じ | ファイルタブ「詳細情報」の情報パネルに5欄が出て、欄を押して打ち Enter で控える。保存で docProps に入り、Excel でも見える |
| 作成者名の削除(配布前に個人名を消す) | 同じ | 情報パネルで作成者の欄を空にして Enter。保存で `dc:creator` が空タグに差し替わる。他の4欄も同じ作法で消せる |
| 保存時にプロパティから個人情報を削除する設定 | 違う形 | 止めるオプションが要らない — 保存がそもそも名前を書き足さない。新規ブックのプロパティは空で、最終更新者を書く仕組み自体が無い。入るのは自分で情報パネルに打った分だけ。Excel がオプトインで守る物を、既定の挙動で守る形 |
| 最終更新者など、画面に出ないプロパティの確認・削除 | まだ無い | 情報パネルは5欄だけ。原本の他の欄(最終更新者・作成日時など)は保存で原文のまま持ち越され、見る道も消す道も無い。Excel で付いた最終更新者は付いたまま渡る(表示側は台帳に残件、消す道は未記載 — 在庫候補) |

## 設定とカスタマイズ・アドイン

Excel のオプション画面に当たるのはファイルタブの「詳細設定」ページで、
中身は `~/.config/office/settings.toml`(置き場も画面に出る)。項目は
ネイティブで意味のある物だけに絞ってある。アドインの登録簿は無く、
拡張は `~/.config/office/plugins/` に置いた .py が全て。詳しくは
[calc の手引き](calc-manual.ja.md)の「共同編集タブとプラグイン」「@コマンド」。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| オプション画面(ファイル > オプション) | 違う形 | ファイルタブの「詳細設定」ページが器で、settings.toml に保存される。項目は言語・画面の明暗・画面の文字の大きさ・反復計算・参照の形式(R1C1)などに絞られ、環境変数(OFFICE_FONT・OFFICE_LANG 等)が一時上書きとして優先する。本家の30項目超の大半は無い |
| リボンのカスタマイズ(独自タブ・釦の並べ替え・設定の書き出し) | 作らない | タブの名前と並びは本家に固定する設計 — 乗り換えた人が場所を覚え直さずに済むことを最優先し、機械ごとに並びが変わる口を作らない。よく使う操作は右クリックと右パネルが受け持つ |
| クイックアクセスツールバーのカスタマイズ | まだ無い | 1段目は保存・印刷・戻す・やり直しの4釦の固定で、足す・減らす口は無い(台帳) |
| リボンの折りたたみ・最小化(Ctrl+F1) | まだ無い | calc の表示タブに帯を畳む釦は無い。writer には「ツールバーを常に表示する」の入切があるので、calc への写しが在庫候補(台帳に未記載 — 在庫候補) |
| 新しいブックの既定フォントとサイズ | まだ無い | 新規ブックの既定の書体を決める設定は無い。詳細設定の「書体(OFFICE_FONT)」は画面表示用で、セルの既定とは別物。当座は範囲を選んでホームの書体・大きさで変える(設定への吸収は予定。台帳に未記載 — 在庫候補) |

| 既定の保存形式の変更(.xls・ODS で保存) | まだ無い | 「名前を付けて保存」で選べるのは xlsx と CSV(いまのシートの値だけ)の2つで、既定を変える設定は無い(印刷=PDF は別の口)。ODS・OTS・XLTX は台帳に控え。古い .xls は読み書きしない |

| 表示言語の変更 | 同じ | 詳細設定の「言語(リボンと文言)」で選び、次の起動から効く(本家も再起動が要るのは同じ)。出るのは文言の揃った言語だけ — 「45言語対応」を名乗らない正直の線。OFFICE_LANG があればそちらが優先 |

| ソルバーアドインの読み込み | 違う形 | アドイン登録という手前の儀式が無い — ソルバーもゴールシークもデータタブに最初から直に並ぶ。解法は単体法 LP ひとつで、非線形は正直に断る |
| 分析ツール(Analysis ToolPak) | まだ無い | 当たる道具はまだ無く、本家ヘルプとの突き合わせ自体が残件。当座は =PY か plugins の手続きから scipy・statsmodels を直に使う(機械に入っている物は全部使える)(台帳) |

## アクセシビリティ

正直に言う — **スクリーンリーダー対応は名乗れる状態ではない**。土台の GPUI に
配管はあるが、こちらは役割も名札も一つも配線しておらず、格子もリボンも
支援技術からは見えない。効くのは画面の文字を大きくする道と、格子の中の
キーボード操作まで。リボンと板(ダイアログ)はキーだけでは届かない。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| リボンやメニューの文字も大きくしたい(本家は OS の設定・拡大鏡が頼り) | 違う形 | アプリ自身が持つ。Ctrl+= / Ctrl+- か表示タブの「画面の文字を大きく/小さく」で 80〜150%。リボン・数式バー・メニュー・見出し・状態行まで全部に掛かり、設定に覚えて次回も同じ大きさで開く(格子のズームとは別軸) |
| キーボードだけでセルの移動・範囲選択・編集 | 同じ | 矢印/Enter(下)/Tab(右)/Shift+Tab(左)で移動、Shift+矢印で範囲、F2 で編集、Ctrl+Home/End・PageUp/Down・Ctrl+A も効く。本家と同じ指が通じる |
| Shift+F10・アプリケーションキーで右クリックメニュー | 同じ | Menu キーと Shift+F10 が右クリックと同じメニューを開く。本家と同じ割り当てである |
| Alt のキーヒントでリボンを操作(Alt→H→…) | まだ無い | 無い。リボンはマウス(またはメニューキー経由の右クリックメニュー)でしか届かず、Alt 系の配線は Alt+Enter(セル内改行)だけである(台帳) |
| 板(ダイアログ)を Tab で渡って釦や欄を選ぶ | まだ無い | 焦点を Tab で渡す仕組みは無く、板の欄や釦はクリックで選ぶ。Enter=確定 / Esc=閉じるだけはほぼ全ての板で効く(終了確認は Enter=保存して終了 / Esc=やめる)(台帳に未記載 — 在庫候補) |
| スクリーンリーダー(ナレーター・NVDA・JAWS)での読み上げ | まだ無い | **対応を名乗れる状態ではない**。土台の GPUI には AccessKit の配管(macOS/Windows/Linux AT-SPI アダプタ)があるが、officework 側は役割(role)や名札を一つも配線しておらず、格子・リボン・状態行は支援技術から見えない(台帳) |
| セルの読み上げ(Speak Cells) | まだ無い | 無い。音声合成・読み上げの実装はどこにも無い(台帳に未記載 — 在庫候補) |
| アクセシビリティチェック(配布前の点検) | まだ無い | 無い。点検機能そのものが存在しない。配布前点検の系(ドキュメント検査)ごと下の「これから埋める節」に残っている |
| 画像・図形の代替テキスト | まだ無い | 無い。図形・画像の設定パネルに代替テキスト欄は無く、xlsx へ書くときも名前しか置かない(読んだ原文は持ち越しで壊さないのみ)(台帳) |
| ダークモード・ハイコントラスト | 違う形 | 表示タブの「インターフェイステーマ」で画面の明暗を切り替えられ、設定に覚えて次回も同じで開く。ただしセル(帳票面)は白のまま — 帳票の見た目は紙が正という設え。OS のハイコントラスト設定への追従は無い |
| 特定のセルへ一発で飛ぶ(F5 / Ctrl+G のジャンプ) | 違う形 | 名前ボックス(数式バー左端)に番地(B12)・範囲(A1:C9)・定義済みの名前を打って飛べる。ただし F5/Ctrl+G は無く、名前ボックスへ入るのはクリックなので、**キーボードだけでは届かない** |
| 音声入力(ディクテーション) | まだ無い | 無い。音声認識の実装も IME 以外の入力経路も無い。OS 側の音声入力(IME 相当)が通ればそれが道になるが、確かめた記録は無い(台帳に未記載 — 在庫候補) |

## 困ったとき(開けない・化けるとき)

約束は3つ — **読めない部品は開くときの報告に出す**(黙って落とさない)、
**理解しない部品は原文のまま持ち越す**(勝手に削らない)、**保存で失われる
物は失われる前にそう言う**。

| Excel での呼び名 | 印 | ここでの道 |
|---|---|---|
| 開いて修復 | まだ無い | 読めなければ「開けません」で止まる。逃げ道は9世代の控え(.jo-history)— 壊れる前の版へ戻れる(台帳に未記載 — 在庫候補) |
| 自動回復・ドキュメントの回復 | まだ無い | 保存は Ctrl+S の手動だけ。未保存はステータスバーに出て、終了時に聞く(自動保存は作らない — 共同編集の節) |
| CSV の文字化け | 同じ | 取り込みウィザードで文字コードを選び直す。使った文字コードを報告 |
| 「他のユーザーがロックしています」 | 違う形 | .~lock を見て誰かを名指しで見せる。後客は読める・上書きは止まる |
| 「修復しました」で部品が消えた | 違う形 | 報告に「名前 × 件数」で列挙し、原文持ち越しで削らない。失われる物は失われる旨まで報告に書く |
| パスワード付きブック | 同じ | Standard/Agile 両読み。忘れたら開けない(裏口なし) |
| シート保護のパスワード忘れ | 作らない | そもそも掛けない(見せかけの錠だから)。同じ釦で外せる — 詰む事故が起きない |
| マクロの警告・保護ビュー | 作らない | 開く=実行が無い(保護の節) |
| 古い .xls が開けない | まだ無い | 読むのは xlsx(zip)だけ。Excel か LibreOffice で xlsx に保存し直す(台帳の方針の節に他形式の割り切りとして記載) |
| 「リンクの更新」を聞かれる | 作らない | 外部参照を作らない設計なので、聞かれる場面が生まれない。取り直しは「外部リンク」でもう一度 |
| Mac 由来の日付が4年ずれる(1904年) | 違う形 | 検出して「4年ずれて見える」と報告。保存は原文持ち越しで date1904 を壊さない |
| 前の版に戻したい | 違う形 | クラウドでなく手元の .jo-history(9世代)。名前のないコピーとして開き、自分で保存して戻す |
| Excel で開き直すとどう見えるか | 同じ | 同じ xlsx。劣化は安全側で各節に明記 — =PY は #NAME? だが値は残る、グラフは画像、ピボットは Excel の保存で値の表に |
| 互換性チェック | 違う形 | ダイアログでなく、開くときの報告とステータスバーが担う。原則は無劣化・失われる物は例外として明記 |
