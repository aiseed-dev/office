# writer の手引き

docx を開いて、直して、保存するワープロ。PDF にもできる。

このマニュアルには**いま動くことだけ**を書く。リボンに灰色で並んでいる
コマンドは未実装で、押せない(できないものを、できるように見せない)。
灰色のものは[巻末](#未実装のもの灰色)に。

3つの約束:

- **書式は据え置き。** 開いた文書のスタイル・図形・理解しない部品は、
  保存しても壊れない(原文のまま持ち越す)
- **どの操作も1手で戻せる。** 打鍵も IME の確定も貼り付けも筆の1本も、
  Ctrl+Z 一回で戻る
- **黙って落とさない。** 読めないもの・保存で失われるものは帳簿と状態行で言う

## 起動

```bash
./target/release/writer            # 空で開く
./target/release/writer 文書.docx
```

日本語フォントが機械に無いと、理由を言って止まる(豆腐を見せない)。
`fonts-noto-cjk` か `fonts-ipaexfont` を入れる。
`OFFICE_FONT=/path/to/font.ttf` で明示もできる。

## 画面

リボンの並びは Euro-Office と同じ:
**ファイル / ホーム / 挿入 / 描画 / レイアウト / 参考資料 / フォーム /
ヘッダー・フッター / レビュー / コラボレーション / 保護 / 表示 / プラグイン**
(本家の全タブ。フォーム等は灰色置き)。
画面の下が状態行。開いた文書に読めない部品(画面に出せないが保存では残る
もの)があれば、左の帳簿に「画像×3」のように出る。

表示タブ: 拡大・縮小(50〜200%。紙は変わらない)、ルーラー(mm 目盛り)、
ダークモード(周りだけ暗くなる — 紙は白いまま。画面と印刷の一致を守る)。

## 基本操作

### キー

| 操作 | キー |
|---|---|
| 移動 | ↑ ↓ ← →(↑↓は見た目の行単位。横位置はなるべく保つ) |
| 語単位の移動 | Ctrl+← / Ctrl+→(日本語は文字種の変わり目) |
| 行頭 / 行末 | Home / End(Home 2度押しで段落の頭 — Word の作法) |
| 文書の頭 / 末尾 | Ctrl+Home / Ctrl+End |
| 選択 | Shift+矢印(語単位は Ctrl+Shift+←→)、Ctrl+A で全部 |
| ページ送り | PageUp / PageDown |
| 元に戻す / やり直し | Ctrl+Z / Ctrl+Shift+Z(Ctrl+Y も同じ) |
| コピー / 切り取り / 貼り付け | Ctrl+C / Ctrl+X / Ctrl+V |
| 検索・置換 | Ctrl+F / Ctrl+H |
| 開く / 保存 | Ctrl+O / Ctrl+S |
| 字下げ | Tab / Shift+Tab(箇条書きの中ではレベルの上げ下げ、表の中では隣のセルへ) |
| 右クリックメニュー | Menu キー / Shift+F10 |
| 板を閉じる・道具を戻す | Esc |
| 終了 | Ctrl+Q(書きかけがあれば確認) |

IME の未確定文字は下線つきで本文に見え、確定した時点で undo の1手になる。

## 文字書式(ホーム)

**選択した字にだけ掛かる**(選択が空なら段落まるごと)。行の中で太字・
大きさ・書体・色が混ざっても、画面も PDF もその通りに出る。

- 太字・斜体・下線・取り消し線(押すたびに入切)
- 上付き・下付き(互いに排他)
- 文字色(赤→青→黒→なし)、蛍光ペン(黄→緑→なし)
- 書体(一覧は**この機械にあるフォント**)、大きさ(一覧から。
  拡大・縮小で 1pt ずつも)
- 大文字小文字の変更(英字のみ)
- スタイルのクリア(文字書式を全部外す。段落の性質は残る)

## 段落書式(ホーム)

- 揃え: 中央・両端(左右は右クリックメニューにも)
- 箇条書き・段落番号。レベルの上げ下げは Tab / Shift+Tab か
  「複数レベルのリスト」
- インデントの増減、行間(1.0→1.5→2.0)
- 段落の前で改ページ(入切)、段落の背景色、囲み枠
- ドロップキャップ(挿入タブ。段落の頭1字を大きく — Word でも見える)
- 非表示文字(段落記号・空白)の表示切り替え

## 見出し・目次・しおり・相互参照(参考資料)

**見出し**: ホーム > 段落のスタイルで「見出し1〜3」を選ぶ(または
参考資料 > テキストの追加で 標準→見出し1→2→3 と回す)。見た目は直接書式で
付き、docx には Heading スタイル + アウトラインレベルで入る(日本語版
Word の「1」も英語版の「Heading1」も読める)。

**目次**: 見出しを付けてから、参考資料 > 目次。ページ番号は**印刷(PDF)と
同じ折り方**で計算するので、目次の番号と紙が食い違わない。見出しを
変えたら「目次の更新」で作り直す。docx には静的な本文として入る —
開いた側に「フィールドを更新してください」と言わせない。

**図表番号と図表目次**: 参考資料 > 図表番号で、段落の下に「図 N」が
中央揃えで入る(採番は自動)。「図表目次」がそれを集めてページ番号つきの
一覧にする。

**しおり**: 参考資料 > ブックマークで板を開き、名前を打って追加。
一覧から選ぶとそこへ飛ぶ。保存で docx に入る。

**相互参照**: 参考資料 > 相互参照で、しおりの「文字」または「ページ」を
参照として本文に挿す。参照はうっすら網掛けで見える(計算された値の印)。
「参照を更新」で計算し直す(この更新だけは undo が効かない — そう言われる)。
docx には REF / PAGEREF フィールドとして入り、Word / LibreOffice でも
表示・再計算できる。参照の中を編集すると普通の字に降りる。

## ヘッダー・フッター

ヘッダー・フッタータブの「ヘッダーの編集」「フッターの編集」で板が開く
(全ページ共通)。板の中で:

- **ページ番号** / **ページ数** — 《ページ番号》の印として入り、
  紙(PDF)で各ページの実番号になる。「3 / 12」のような形も作れる
- **日付/時刻** — 挿した時点の日付が「2026年8月4日」の形で**固定の文字**
  として入る(開くたびに変わるフィールドにはしない — 事務書類で「今日」に
  化けるのは事故のもと)

Esc で閉じる。画面の紙は巻物なので、ヘッダー・フッターは先頭と末尾に
灰色で出る — 本当のページ番号は PDF で入る。表の入ったヘッダーは
この版では編集できない(そう言われる。保存では原文のまま残る)。

## 表

- **挿入 > 表の挿入** で 3×3 の表が入る
- セルをクリックすると**セルの中で編集**できる。Tab / Shift+Tab で隣の
  セルへ、↑↓で上下のセルへ
- セル結合された表は読み・表示・保存・PDF とも対応(結合を**作る** UI は
  まだ無い)
- テキストボックスが欲しいときは 挿入 > テキストボックス — 1×1 の表が
  入る(枠の中に文字が書ける)

## 画像(挿入)

**挿入 > 画像を挿入** で PNG・JPEG・SVG を選ぶ。行長に収まらなければ
比例で縮む。**SVG は3倍スケールの高精細 PNG に変換して**貼る(matplotlib
の `savefig("図.svg")` がそのまま使える)。保存で docx の部品
(media / rels)ごと入り、Word / LibreOffice でも見える。

図形・グラフ・SmartArt・テキストアート・方程式の釦も「画像を挿入」と同じ
道につながる — **絵は Python(matplotlib / PIL)で描いて、画像として貼る**
のがこのソフトの流儀。開いた文書にある図形・グラフは画面に出ないが、
保存では壊れない(帳簿に出る)。

**ファイルからのテキスト**: .txt / .md / .docx の中身をカーソル位置に
差し込む。

## 描画(ペン・蛍光ペン・消しゴム)

描画タブで道具を選び、紙の上をドラッグ。もう一度押すか Esc で文字編集に
戻る。

- **ペン**: 細く、濃く、文字の上
- **蛍光ペン**: 太く、薄く、文字の下
- **消しゴム**: なぞった線を1筆ずつ消す
- 筆は**ページに固定** — 本文を編集しても動かない。1筆が undo の1手
- docx では自由曲線の図形になり、Word / LibreOffice でも普通の図形として
  見える。このアプリ同士なら開き直しても消しゴムが効き続ける

## レイアウト

- 用紙(A4→B5→A3)、向き(縦横)、余白(標準20mm→狭い12mm→広い30mm)
- 段組み(1→2→3段)。画面と PDF は同じ折り方
- 行番号の表示、ページ色(なし→薄クリーム→薄青→薄緑)
- **透かし**: 板に文字を打つと、斜めの薄い字が全ページの背景に入る。
  空にすると外れる。Word でも見える
- **ハイフネーション**: 入にすると欧文の長い語を音節で折って行末に `-`
  (TeX と同じ分綴パターン)。日本語には影響しない(禁則で折るだけ)

## 検索と置換

Ctrl+F(または Ctrl+H・ホーム > 置き換え)で板が開く。検索語を打って
Enter で次の一致へ(末尾まで行ったら頭から)。置換欄に入れて置き換え、
「すべて置換」は**何件変えたかを言う**。Esc で閉じる。

## レビュー

### コメント

レビュー > コメントで、カーソルの段落にコメントが付く(段落単位)。
保存で docx に入り、Word で吹き出しとして見える。

### 変更履歴

レビュー > 変更履歴で**記録の開始/停止**。記録中は、変わった段落の左に
橙の変更バーが出る。編集は普通にできて、**保存のときに**記録開始時点との
差分が Word の本物の変更履歴(挿入・削除、著者つき)として docx に入る。

注意: **保存すると履歴は確定される**(帳簿でそう言われる)。履歴の中身の
閲覧・個別の採否はまだできない。

### 校正(スペルチェック)

- **英語の綴り**は機械の辞書で見る(`/usr/share/dict/words` など)
- **日本語の誤変換(以外/意外)・表記ゆれ(問合せ/問い合わせ)**は辞書では
  出ないので、ローカルのモデルに聞く。宛先は OpenAI 互換の
  `/v1/chat/completions`:

```bash
OFFICE_HOST=127.0.0.1 OFFICE_PORT=8000 OFFICE_MODEL=... ./target/release/writer
```

- モデルの作り話は通さない(本文に実在しない指摘は捨てる)
- **繋がらなければ「校正できません」と出る。** 黙って「指摘なし」には
  しない — 「誤りが無い」と受け取らせないため
- 基幹網の外には出ない(宛先はローカル)

画面を開かずに使う単体ツールもある:

```bash
office-spell 文書.txt        # 指摘を出す(終了コード 0=無し 1=あり 2=読めない 3=検査しきれず)
office-spell -l              # 辞書に無い語だけ
office-spell --furigana 原稿.txt
```

### 文字カウント

日本語の実情に合わせ、「単語数」ではなく**文字数**と段落数を出す。

## 共有フォルダと排他ロック

calc と同じ。開くとき LibreOffice と同じ場所の `.~lock.文書.docx#` を見て、
先客がいれば**誰が開いているか**を見せ、上書き保存を止める(名前を付けて
保存へ)。誰もいなければ自分のロックを置き、閉じるときに外す。

## PDF

ファイル > 印刷で PDF に保存する。画面の紙面をそのまま写すので、
**画面と紙は食い違わない**。入るもの: 本文・表・画像・ヘッダー・フッター
(各ページの実番号)・透かし・ページ色・ペンと蛍光ペン。
コメントは入らず、変更履歴は確定後の姿で出る。

## 保存

- Ctrl+S で上書き(先客のロックがあれば止まる)
- 本文・表・画像・ヘッダーは書き戻し、スタイル定義・設定・理解しない
  部品は**原文のまま**持ち越す
- 読めなかった要素があれば「本文に戻りません(保存では残ります)」と
  付記される
- Python から docx を作る仕事には **python-docx がそのまま使える**
  (その保存を writer が読めることは実物で確認済み。xlsx と違い、
  writer 用の橋は作らない方針)

## 未実装のもの(灰色)

リボンは 77/91 実装済み。灰色のまま残っているもの:

- テキスト方向(縦書き)・配色の変更・コンテンツコントロール
- コラボレーション(共同編集・チャット・バージョン履歴)
- 保護(暗号化・デジタル署名)
- プラグイン・マクロ(**マクロは作らない方針** — 文書の中に実行コードを

ルビ・均等割付もまだ無い。
